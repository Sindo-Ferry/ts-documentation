The **Timeslots** page shows all of the departure timeslots that belong to **your
ferry operator**. It is a **read-only** view — you can browse and filter the
timeslots, but you cannot change them here.

> **Timeslots → view / filter (read-only)**

:::note
The screenshots below use `https://ts-operator.sindoferry.com.sg/`.
:::

## Prerequisites

- You are signed in to the Operator Portal — see
  [Sign In to the Operator Portal](/ferry-operator/operator-sign-in).

## The Timeslots list

Open **Timeslots** (route: `/departure-timeslots`). The table lists your operator's
timeslots, each showing:

| Column | Notes |
| --- | --- |
| **Route** | The route the timeslot runs on. |
| **Default Vessel** | The vessel assigned to trips generated from this timeslot. |
| **Departure** | The departure time, with the **Gate** open–close window below it. |
| **Days** | The days it runs (Mon–Sun), plus **PH** with the country codes whose public holidays it runs on — e.g. **PH (SG, ID)**. |
| **Status** | **Active** or **Inactive**. |

Use the filter toolbar to narrow by **route**, **status**, or **day**.

![The operator's read-only Timeslots list](/img/ferry-operator/timeslots/01-list.png)
_The Timeslots list — Route, Default Vessel, Departure, Days, and Status._

:::info[Read-only — changes are made by the terminal]
This page has **no create, edit, or delete actions**. Timeslots are master data
managed by **terminal staff** in the Terminal Portal. If a timeslot needs to be
added or changed, ask the terminal to update it — see the terminal
[Timeslots](/terminal-staff/timeslots) guide.
:::
