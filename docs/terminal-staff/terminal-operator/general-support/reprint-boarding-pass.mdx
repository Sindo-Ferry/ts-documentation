Passes get lost, spilt on, and left in taxis. Reprinting one is quick, and — this is
the important part — it **reissues the same boarding pass number**. The old pass and
the new one are the same pass.

> **Current Trips → open the trip → printer icon (or download icon) on the passenger's row**

## Step 1 — Find the passenger

From within their trip:

- **Today's trip:** **Operational → Current Trips** → click the trip → the
  **Passengers** table at the bottom.
- **An older trip:** **Management → Departure Trips** → find the trip → open its
  detail page.
- **Not sure which trip?** [Look Up a Passenger](/terminal-operator/look-up-passenger)
  first — it searches every trip and tells you which one they are on.

The table's **BP No** column shows each passenger's boarding pass number, which is a
quick way to confirm you have the right row.

## Step 2 — Use the printer or download icon

At the right-hand end of the passenger's row, **before** the **⋯** menu, are two
small icon buttons:

| Icon | What it does |
| --- | --- |
| 🖨 **Printer** | Opens the boarding pass and sends it to print. |
| ⬇ **Download** | Saves the boarding pass as a PDF, named `boarding-pass-<number>.pdf`. |

:::warning[They are not inside the ⋯ menu]
These are **separate icon buttons sitting next to** the **⋯** menu, not items in it.
People hunt through the dropdown and conclude the feature is missing. Look to the
left of the three dots.
:::

Both icons show a spinner while the pass is being generated.

## Step 3 — Check the number

The reprinted pass carries the **same boarding pass number as before**. Reprinting
never generates a new one. A passenger holding an old printout and a new printout has
two copies of the same pass — either one scans.

The only thing that produces a **new** number is checking the passenger in again
from scratch, which means
[cancelling](/terminal-operator/cancel-passenger) them first.

## When the icons are greyed out

Hover for the tooltip, which names the reason:

| Tooltip | What it means | What to do |
| --- | --- | --- |
| **"This passenger has no boarding pass number."** | No pass was ever issued for this record. | Rare. Check the record was created properly; it may need to be cancelled and re-checked-in. |
| **"This passenger is cancelled."** | Cancelled passengers have no valid pass. | If they are travelling after all, [check them in again](/terminal-operator/check-in-ntl-lm) — they get a new number. |
| **"This trip is cancelled."** | The whole sailing is off. | Nobody on a cancelled trip has a valid pass. |
| **"Loading trip…"** | The page is still fetching the trip. | Wait a moment. |

If you see **no icons at all**, you do not hold the boarding-pass permission — ask
your administrator.

## Step 4 — Check the issue history (optional)

To see how many times a pass has been issued and by whom, open the row's **⋯** menu
and choose **Boarding Pass History**.

Each entry shows:

- **who** issued it,
- **when**, and
- a badge reading **Terminal** or **Operator**, so you can tell a terminal reprint
  from one done at the ferry operator's own counter.

If nothing has been issued yet, it reads _"No boarding pass issued yet."_

This is the quickest way to answer "has this passenger already been given a pass
today?" — and to see whether a colleague printed one two minutes ago.

## Common situations

| Situation | What to do |
| --- | --- |
| Passenger lost their pass | Reprint. Same number; their scan will work. |
| The printout is smudged and the barcode will not scan | Reprint. Failing that, type the 16-character number into the scan field by hand — it is in the **BP No** column. |
| Passenger wants it on their phone | Use the **download** icon and send them the PDF. |
| The printed name is wrong | [Edit the passenger](/terminal-operator/edit-passenger) first (only possible while CheckedIn), **then** reprint. |
| Passenger insists they never got one | Check **Boarding Pass History** before reprinting. |
| Pass was issued at the operator's counter and they want another | Reprint from here. The history will show both issues, tagged Operator and Terminal. |
