A **gate** is a boarding gate at a port. When a trip is set to
[Boarding](/terminal-staff/manage-departure-trip#1-set-as-boarding), staff assign it
a gate (and a [berth](/terminal-staff/berths)) — only **active** gates at the trip's
port are selectable.

> **Gates → Create Gate / Actions (Edit · Activate · Delete)**

:::note
You need permission to manage gates. The screenshots below use
`https://ts-terminal.sindoferry.com.sg/`.
:::

## The Gates list

Open **Gates** (route: `/gates`). Each row shows the gate's **Code**, its **Name**,
its **Port**, and **Status** (**Active** / **Inactive**), plus an **Actions** (**⋯**)
menu. Use the **search** box (matches code and name) and **Show Filters** (Port,
Status) to narrow the list.

![The Gates list view](/img/terminal-staff/gates/01-gates-list.png)
_The Gates list — Code, Name, Port, and Status. Note **G1** appearing at two different ports: codes only have to be unique **within** a port._

## Create a gate

Click **Create Gate** (top right) and fill in the **New Gate** form:

| Field | Notes |
| --- | --- |
| **Port** | The port the gate belongs to — choose this first. |
| **Gate code** | The gate's code, e.g. `G1`. |
| **Name** | A descriptive name, e.g. `North Wing Gate 1`. |
| **Active** | Whether the gate is available for assignment. Ticked by default. |

Then click **Create Gate**.

![The New Gate form, with Port, Gate code, Name, and an Active checkbox](/img/terminal-staff/gates/02-create-gate.png)
_Creating a gate — pick the **Port** first, then the code and name._

:::warning[Unique within the port]
The **Gate code** must be **unique within the selected port** (two ports can each
have a gate `G1`, but one port cannot have two).
:::

## Edit, activate/deactivate, and delete

From the row **⋯ Actions** menu you can **Edit** the gate, **Activate / Deactivate**
it (only active gates can be assigned to a boarding trip), or **Delete** it
(confirmation required).
