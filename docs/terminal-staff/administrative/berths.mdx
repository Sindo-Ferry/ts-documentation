A **berth** is a docking position at a port. When a trip is set to
[Boarding](/terminal-staff/manage-departure-trip#1-set-as-boarding), staff assign it
a berth (and a [gate](/terminal-staff/gates)) — only **active** berths at the trip's
port are selectable.

> **Berths → Create Berth / Actions (Edit · Activate · Delete)**

:::note
You need permission to manage berths. The screenshots below use
`https://ts-terminal.sindoferry.com.sg/`.
:::

## The Berths list

Open **Berths** (route: `/berths`). Each row shows the berth's **Code**, its
**Name**, its **Port**, and **Status** (**Active** / **Inactive**), plus an
**Actions** (**⋯**) menu. Use the **search** box (matches code and name) and
**Show Filters** (Port, Status) to narrow the list.

![The Berths list view](/img/terminal-staff/berths/01-berths-list.png)
_The Berths list — Code, Name, Port, and Status. Note **B1** appearing at two different ports: codes only have to be unique **within** a port._

## Create a berth

Click **Create Berth** (top right) and fill in the **New Berth** form:

| Field | Notes |
| --- | --- |
| **Port** | The port the berth belongs to — choose this first. |
| **Berth code** | The berth's code, e.g. `B1`. |
| **Name** | A descriptive name, e.g. `East Pier Berth 1`. |
| **Active** | Whether the berth is available for assignment. Ticked by default. |

Then click **Create Berth**.

![The New Berth form, with Port, Berth code, Name, and an Active checkbox](/img/terminal-staff/berths/02-create-berth.png)
_Creating a berth — pick the **Port** first, then the code and name._

:::warning[Unique within the port]
The **Berth code** must be **unique within the selected port**.
:::

## Edit, activate/deactivate, and delete

From the row **⋯ Actions** menu you can **Edit** the berth, **Activate /
Deactivate** it (only active berths can be assigned to a boarding trip), or
**Delete** it (confirmation required).
