A **public holiday** marks a date that the system treats specially when generating
trips. On a public-holiday date, a [Trip Sync Job](/trip-sync-job) applies only the
[timeslots](/terminal-staff/timeslots) whose **Public Holiday** flag is ticked
(weekday flags are ignored that day). Maintaining this list keeps holiday sailings
correct.

> **Public Holiday → Create Public Holiday / Actions (Edit · Delete)**

:::note
You need permission to manage public holidays. The screenshots below use
`https://ts-terminal.sindoferry.com.sg/`.
:::

## The Public Holiday list

Open **Public Holiday** (route: `/public-holidays`). Each row shows the holiday's
**Date** and **Description**, plus an **Actions** (**⋯**) menu.

- **Search** — type in the **search** box to find a holiday by its description.
- **Filter by year** — narrow the list to a single **Year**.

![The Public Holiday list view with the search and year filter](/img/terminal-staff/public-holiday/01-list.png)
_The Public Holiday list — Date and Description, with search and a Year filter._

## Create a public holiday

Click **Create Public Holiday** (top right) and fill in the **New Public Holiday**
form:

| Field | Notes |
| --- | --- |
| **Date** | The holiday date. |
| **Description** | A label for the holiday, e.g. `New Year's Day`. |

Then click **Create Public Holiday**.

![The New Public Holiday form](/img/terminal-staff/public-holiday/02-create.png)
_Creating a public holiday._

:::warning[One holiday per date]
Each **date** can have only **one** public holiday — the system rejects a second
entry for a date that already has one.
:::

## Edit and delete

From the row **⋯ Actions** menu you can **Edit** a holiday's date or description, or
**Delete** it (confirmation required).

:::tip[Effect on trips]
Public holidays only affect trips for **dates going forward** — a Trip Sync Job run
over a range containing a holiday date will use the **Public Holiday** timeslots for
that day. Existing trips are not changed retroactively; re-run the sync if you add or
remove a holiday for an already-generated period.
:::
