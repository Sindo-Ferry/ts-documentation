Export the Passenger Manifest Report

The Passenger Manifest report is the full-options version of the manifest. Where the trip page's Download Manifest button always gives you an Excel file of boarded passengers, this form lets you choose the format, the language, which passengers to include, and whether to password-protect the result.

Reports → Passenger Manifest → choose the trip and options → Download Report

note

You need the manifest-report permission; without it the Reports item does not appear in the sidebar. The screenshots below use https://ts-operator.sindoferry.com.sg/.

Before you start​

  • You are signed in with the right operator selected — see Sign In.
  • You know which trip you want. The picker lists your own trips only.

Step 1 — Open the report​

In the sidebar, open Reports (route: /reports). The page lists the reports you have access to; click Passenger Manifest — "Boarding / passenger list for a departure trip."

The Reports page, with the Passenger Manifest card.

If the list reads "You don't have access to any reports," ask your administrator.

Step 2 — Fill in the form​

FieldOptionsDefault
Departure TripClick Select trip and pick from your operator's trips. Required.—
FormatExcel (.xlsx) or PDF (.pdf)Excel
LanguageEnglish or IndonesianEnglish
Passenger StatusAll passengers, or one of CheckedIn, PreImmigration, Boarded, CancelledBoarded
Password (optional)Protects the generated file. Only shown when Format = PDF.blank

The form with a trip picked and the defaults — Excel (.xlsx), English, Boarded. The Password field is not shown because the format is Excel.

Then click Download Report. The button reads Generating… while it works.

Choosing the passenger status​

This is the setting that makes the report worth using:

StatusWhat you getTypical use
Boarded (default)Only passengers scanned aboard.The official manifest of who sailed.
All passengersEveryone on the trip, whatever their status.Reconciling bookings against who actually travelled.
CheckedInChecked in but not boarded.Chasing no-shows after departure.
PreImmigrationCleared pre-immigration but never boarded.Investigating passengers left behind.
CancelledCancelled bookings only.Refunds and cancellation records.
The default is Boarded, not everyone

Leave the form untouched and you get Boarded passengers only — the same as the trip page's Download Manifest button. If you need the full list, you must change Passenger Status to All passengers.

Password protection​

Password applies to PDF only

The Password (optional) field only appears when Format = PDF. Switch the format to Excel and it disappears — Excel output cannot be password-protected here, and the export service rejects the attempt.

The field's own hint says so: "Protects the generated PDF. Only available for the PDF format."

To protect a report:

  1. Set Format to PDF (.pdf).
  2. Type a password into Password (optional) — it is masked as you type.
  3. Download Report. Opening the file then asks for that password.

Leave it blank and the PDF opens normally.

The password is not stored anywhere

Nothing records what you typed. If you are sending a protected manifest on, pass the password to the recipient through a separate channel — and keep your own note of it. Regenerating the report with the same password is the only way back in.

What you get​

A file named:

passenger-manifest-<TRIP-CODE>-<TRIP-DATE>.pdf   (or .xlsx)

The extension follows the Format you chose. The content is the same manifest data in either case — the trip's details plus a row per passenger matching your status filter.

Use the button for the everyday manifest; use the report when you need a different format, a different set of passengers, or protection.

Only your own operator's data​

The Departure Trip picker lists your operator's trips only, and the generated file contains only your own passengers. The totals should reconcile exactly against the trip's passenger table.

Another operator's trip or passenger appearing anywhere here is a serious problem — stop and report it to your administrator.
