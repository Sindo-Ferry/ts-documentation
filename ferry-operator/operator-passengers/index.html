Passengers

The Passengers page shows your operator's passenger records. It is a read-only view — you can search, filter, and open a passenger's full details, but you cannot edit or change status from here.

Passengers → search / filter → Actions → View Passenger

note

The screenshots below use https://ts-operator.sindoferry.com.sg/.

Prerequisites​

  • You are signed in to the Operator Portal — see Sign In to the Operator Portal.

The Passengers list​

Open Passengers (route: /passengers). Each row shows the passenger's Trip (code), No (passport / ID), Name, Type, Status, and Nationality, plus an Actions (⋯) menu. Use the search box and Show Filters (for example, by trip date) to narrow the list.

The Passengers list — Trip, No, Name, Type, Status, and Nationality.

Scheduled trips only

This page lists only passengers on trips that are still Scheduled, and it opens on today's trip date. Once a trip moves on — to Boarding, Closed, Departed, or Cancelled — its passengers stop appearing here, even if you widen the trip-date filter to cover that day. This is expected: the page is meant for trips that have not yet sailed.

To see the passengers on a trip that has already departed, open the trip instead: Departure Trips → find the trip → View. The Departure Trip Detail page lists every passenger on that trip with their final status, and offers Download Manifest.

View a passenger​

The row ⋯ Actions menu offers a single action — View Passenger — which opens a read-only details page for that record, grouped into three sections:

  • Trips Informations — Trip Code, Trip Date / Departure, Trip Status, Trip Type, Route, and Vessel.
  • Passport Informations — No, Name, Gender, Date of Birth, Issuance Date, Nationality, Issuance Country, and Passport Expiry Date.
  • Check In Informations — Boarding Pass No, Type, Status, Checked-in At, Pre-Immigration At, Boarded At, and whether the passenger was Cancelled.

The View Passenger page — trip, passport, and check-in details.

Read-only

This page (and the detail view) is read-only — there are no edit, status, or other passenger actions here. Passenger check-in and edits are done from the Check In a Passenger and Edit & Remove a Checked-In Passenger flows.
