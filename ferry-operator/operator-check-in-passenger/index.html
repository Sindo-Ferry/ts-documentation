Check In a Passenger

Ferry operators can add a passenger directly onto a departure trip. The passenger is recorded against the trip, issued a boarding pass, and shown in the trip's passenger list with status CheckedIn.

Departure Trips → Filter the trip → View → Check In Passenger → CheckedIn

What operators can check in

Through the Operator Portal, ferry operators check in Ordinary passengers only. Check-in is available only on upcoming trips that are still in Scheduled status — once a trip starts boarding (or is closed, departed, or cancelled) it no longer accepts check-ins here — and the trip must have available seats.

note

You must be signed in and have an operator workspace selected — see Sign In to the Operator Portal. The screenshots below use https://ts-operator.sindoferry.com.sg/.

Prerequisites​

  • You are signed in and have selected your operator.
  • The departure trip exists for the date you want.

Step 1 — Open Departure Trips and filter to the trip​

From the sidebar, open Departure Trips. The trips are shown as a grid of days × departure times. Use Show Filters to narrow the results — for this guide, set both From Date and To Date to today so only today's trips remain.

Departure Trips filtered to a single day. Each trip card has a View button.

Step 2 — View the target trip​

Find the trip you need (for this guide, the last trip of the day) and click View on its card. The Departure Trip Detail page opens, showing the trip info and a Passengers section with the Check In Passenger button.

The trip detail page. Checked-in passengers appear in the Passengers table.

Step 3 — Check in the passenger​

Click Check In Passenger and complete the form:

FieldNotes
NoPassport / ID number.
NamePassenger's full name.
GenderOptional; defaults to Unspecified.
NationalityRequired — pick from the country list.
Date of BirthRequired (YYYY-MM-DD).
Expiry DateRequired — travel-document expiry.
Issue Date / Issue CountryOptional travel-document details.

Then click Check In Passenger.

The Check In Passenger form. Date of Birth and Expiry Date are required.

No duplicate passengers

Each passenger can be checked in once per trip. If the No (passport / ID number) you enter is already checked in on the same trip, a Validation Failed message appears — "A passenger with this No already exists on this trip" — and the passenger is not added. Correct the number, or find the existing entry in the Passengers list, then try again.

Checking in a passenger whose No is already on the trip is rejected.

Outcome​

The passenger is added to the trip as an Ordinary passenger and appears in the Passengers table with:

  • Status: Checked-In — from here the passenger progresses through Pre-Immigration and Boarded as they are scanned (or can be Cancelled).
  • A unique boarding pass number — the passenger's reference for the rest of the boarding process, so make sure it's captured.

The trip's Checked-In count and Load increase accordingly.

tip

Use the Passengers search or Show Filters on the trip detail page to find a specific passenger, and Download Manifest to export the full list.
