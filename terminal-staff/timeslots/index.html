Timeslots

A timeslot is a recurring weekly schedule template: it defines an operator's service on a route — the vessel, the gate-open/close and departure times, and which days it runs. Timeslots are the source that a Trip Sync Job turns into actual departure trips.

Timeslots → Create Timeslot → Save Timeslot → (Calendar / List views)

note

You need permission to manage timeslots. The screenshots below use https://ts-terminal.sindoferry.com.sg/.

Prerequisites​

  • You are signed in to the Terminal Portal — see Sign In to the Terminal Portal.
  • The operator, route, and an active vessel for that operator already exist — a timeslot is where those three come together.

Create a timeslot​

Open Timeslots and click Create Timeslot. Fill in the form:

FieldNotes
OperatorThe operator running the service (e.g. Waterfront Ferry).
RouteThe route (e.g. WFC - TMFT — Waterfront to Tanah Merah).
Default VesselThe vessel to assign. The picker is enabled after you choose an operator and lists only that operator's vessels.
Gate Open / Gate Close / DepartureThe timings — e.g. depart at 11:20 AM.
Suffix (optional)Distinguishes timeslots that share the same operator, route, and departure time (see the note below).
DaysTick Weekday, Weekend, Public Holiday, or individual days — All Days ticks everything.
Public Holiday countriesAppears when Public Holiday is ticked — pick at least one country whose public holidays this timeslot runs on. Select countries opens a checkbox table: tick several rows (the header checkbox ticks the whole page), then Done. Picked countries show as chips you can remove individually.
ActiveTicked by default. Only active timeslots are picked up by Trip Sync Jobs.

Then click Create Timeslot.

Creating a Waterfront Ferry timeslot on WFC - TMFT, departing 11:20 AM — running Monday–Friday and additionally on ID and SG public holidays, shown as removable chips.

Validation rules

The backend enforces these when you save:

  • Times must be in order: Gate Open ≤ Gate Close ≤ Departure.
  • The Default Vessel must belong to the selected operator and be active.
  • Timeslots that share the same operator, route, and departure time must have a different Suffix (otherwise they would generate identical trip codes).
  • Public Holiday requires at least one country — a timeslot with the flag ticked but no countries selected is rejected.

Calendar and List views​

Once created, the timeslot appears in both the Calendar and List views, each with a filter (operator, route, status, and — in the list — day). Use the Calendar / List toggle at the top right to switch.

Calendar view​

The Departure Timeslot Weekly Grid lays out timeslots by departure time (rows) across days (columns), with PH as the last column. Each card shows the operator, route, vessel, and Active/Inactive status; in the PH column the card also carries a small tag with the timeslot's holiday country codes. Empty cells show + Add to create a timeslot for that time and day.

  • Select to group — click a card to select the whole timeslot: every day it runs on is highlighted together, making it easy to identify the schedules that belong to the same timeslot.
  • Double-click to edit — double-click a card to open its edit form.

Selecting the 07:00 timeslot highlights every day it runs on as one group — Mon–Sun and the PH column, whose card carries its ID and SG tags.

List view​

The list shows each timeslot's operator (with day badges), route, vessel, departure (with the gate open–close window), and status. A holiday-running timeslot's badge includes its country codes — e.g. Public Holiday (ID, SG). A timeslot that does not run on holidays simply has no such badge.

The list view, filtered to Harbourfront to Waterfront — each row's day badges show Weekday, Weekend, and where applicable Public Holiday with its country codes.

From the row ⋯ Actions menu you can:

  • Edit — open the timeslot's form.
  • Activate / Deactivate — toggle whether the timeslot is used by Trip Sync Jobs.
  • Delete — remove the timeslot.

The Actions menu — Edit, Deactivate, and Delete.

Activation needs an active vessel

A timeslot can only be activated while its default vessel is active. If the vessel has been deactivated, reactivate it (or change the timeslot's vessel) first.

From timeslot to departure trip​

Timeslots are templates — they are not trips by themselves. To turn them into the actual departure trips used across the check-in → boarding → depart process, an authorized user runs a Trip Sync Job. Every active timeslot that matches the job's criteria (operator, route, days) is generated as a departure trip for each matching date in the job's date range. On each date, a timeslot runs when its weekday flag for that day is ticked — and additionally on any date that is a public holiday in one of its Public Holiday countries. Holidays never suppress the weekday schedule; see Which timeslots run on a date.
