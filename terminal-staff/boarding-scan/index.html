Boarding Scan

Once passengers clear pre-immigration, they move to the final boarding gate. On this page, operational staff scan each passenger's boarding pass to board them onto the trip, with a public Passenger Display for the gate.

Current Trips → select the trip → Set As Boarding (gate & berth) → scan boarding pass

Restricted access

This page can only be accessed by authorized operational staff.

note

The screenshots below use https://ts-terminal.sindoferry.com.sg/.

Prerequisites​

  • You are signed in to the Terminal Portal — see Sign In to the Terminal Portal.
  • You have set your active port.
  • The trip exists in Current Trips and passengers have cleared pre-immigration.

Step 1 — Open Current Trips and select today's trip​

Open Current Trips (route: /current-departure-trips) and select an active trip scheduled for today.

Step 2 — Set the trip to Boarding​

Open the boarding module for that trip. If the trip is still Scheduled, set its status to Boarding first by assigning a gate and berth — see Manage Current Trip Status → Set As Boarding for the full gate/berth steps.

Step 3 — The Boarding Scan page​

Setting the trip to Boarding launches the Boarding Scan page for that trip. The pre-immigration passenger list (passengers ready to board) is shown on the right side.

The Boarding Scan page — scan field on the left, ready-to-board passengers on the right.

Step 4 — Set up the Passenger Display​

Next to the scanning field, click Open Passenger Display to launch the dedicated gate interface. As before, drag this window onto a second monitor and press F11 for full-screen mode so it faces the passengers.

The Passenger Display — the ready-for-scan gate screen shown to passengers.

Step 5 — Scan the boarding pass​

Back on your operator screen, click into the active scanner input field. You can either type a valid Boarding Pass Number and press Enter, or use a hardware scanner to scan the physical barcode.

Step 6 — Outcome (operator screen and Passenger Display)​

On a successful scan, the operator view instantly processes the boarding pass and updates the trip metrics (Boarded count). At the same time, the Passenger Display on the second screen shows a Success or Reject message with the relevant passenger details.

A successful scan — the passenger is boarded.

A rejected scan — the passenger is not boarded; check the message and try again.

Step 7 — Revert a boarded passenger​

If a boarded passenger needs to be reverted, simply re-scan their boarding pass number. The Revert To Pre-Immigration button is shown again for that scanned boarding pass, and the boarding-gate staff can click Revert to move the passenger back — removing them from the active Boarded count.

tip

Reverting returns the passenger to Pre-Immigration, so they can be boarded again with another scan when they are ready.

Next steps​

  • Passenger Manifest — download the boarded-passenger manifest after departure.
  • Manage Current Trip Status — close the trip and record departure once boarding is done.
