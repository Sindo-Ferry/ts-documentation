Manage Current Trip Status

A departure trip moves through a one-way lifecycle. Terminal staff drive it from Current Trips: open boarding, close boarding once everyone is aboard, then record the departure.

Scheduled → Set As Boarding → Set As Close → Set As Depart → Departed

Restricted access

Current Trips can only be accessed by authorized operational staff.

note

The screenshots below use https://ts-terminal.sindoferry.com.sg/.

Prerequisites​

  • You are signed in to the Terminal Portal — see Sign In to the Terminal Portal.
  • You have set your active port.
  • The trip exists in Current Trips.

Departure-trip status reference​

A departure trip moves through the statuses below. The normal lifecycle is Scheduled → Boarding → Closed → Departed; a trip may instead be Cancelled.

StatusWhat it meansHow it gets there
ScheduledPlanned and listed, but not yet open for boarding.Created by a Trip Sync Job
BoardingBoarding is open; passengers can board.Set As Boarding (requires gate & berth)
ClosedBoarding is closed; no more passengers can board; ready for departure.Set As Close
DepartedThe trip has departed; the trip is finalized.Set As Depart
CancelledThe trip has been cancelled and will not run.Cancel action

1. Set As Boarding​

When a scheduled trip is ready for passengers, move it to Boarding and assign the gate and berth it will use.

Current Trips → select the trip → Set As Boarding → assign Gate & Berth

Open Current Trips and select the trip​

Open Current Trips (route: /current-departure-trips) and click the trip you want to board. Its detail page opens.

(For screenshots of the Current Trips list and the trip detail page, see Check In an NTL / LM Passenger, Steps 1–2.)

Click Set As Boarding​

On the trip's detail page, while the Status is Scheduled, click Set As Boarding (top right). The Gate / Berth field shows - / - until you assign them in the next step.

A Scheduled trip. The Set As Boarding button is at the top right.

Assign a gate and berth​

A dialog opens: Assign a gate and berth … to begin boarding.

  1. Click Gate and pick an active gate from the picker (filtered to the trip's port and to Active gates).
  2. Click Berth and pick an active berth the same way.
  3. Click Set As Boarding to confirm.

The Set As Boarding dialog — choose a Gate and Berth, then confirm.

The gate picker lists active gates for the trip's port; the berth picker works the same way.

tip

Only active gates and berths at the trip's port are selectable. If the one you need isn't listed, check that it exists and is marked active under the port's master data.

Boarding begins​

Once you confirm, the trip's Status changes to Boarding and you are taken to the trip's Boarding Scan page, where the boarding process is run.

The Boarding Scan page for a trip that is now Boarding.

From this page you can:

  • See the trip detail — operator, vessel, departure time, gate / berth, destination port, and live counts (Check-In, Pre-Imm, Boarded).
  • Scan boarding passes — enter or scan a Boarding Pass Number to board a passenger. See Boarding Scan for the full scanning workflow.
  • Revert a boarded passenger to Pre-Immigration — after a successful boarding scan, the scanned passenger's card shows a Revert to Pre-Immigration button that moves that passenger back to the Pre-Immigration state when needed for operational reasons. See Boarding Scan → Revert a boarded passenger for details.
  • Work the passenger list — a filterable list that, by default, shows passengers who have cleared pre-immigration and are ready to board (the Status: PreImmigration filter). Search or change the filters as needed.
  • Open the Passenger Display — launch the separate boarding-pass scan display shown to passengers.
  • Close the trip — when boarding is finished, use Set As Close (top right), covered next.

You can also check in NTL / LM passengers onto the trip while it is boarding.

2. Set As Close​

When boarding is complete, close the trip. Closing stops any further boarding and marks the trip ready for departure.

This cannot be undone

Closing a trip is final. Once closed, no more passengers can board and the trip must be ready for departure — boarding cannot be reopened.

Where to close a trip​

You can set a trip as close from two places:

  1. From Current Trips — open Current Trips, select the Boarding trip to open its detail page, then click Set As Close.
  2. From the Boarding Scan page — when the boarding scan is finished, click Set As Close at the top right of the Boarding Scan page (shown above).

Confirm and outcome​

A Set As Close confirmation appears, showing the trip's code, date, and departure time. It reminds you that no further passengers can board, that the trip can then be departed, and that the action cannot be undone. Click Set As Close to confirm.

Passengers still in Pre-Immigration

If any passengers have cleared pre-immigration but have not boarded, the dialog shows an amber warning first — "N passenger(s) still in Pre-Immigration — they have not boarded yet. Closing this trip will prevent them from boarding."

The warning is there for you to confirm the closure deliberately; it does not block you. If those passengers are still expected, Cancel, board them from Boarding Scan, and close the trip afterwards. Otherwise, go ahead and close — they will be left behind.

Closing a trip that still has a passenger in Pre-Immigration — the amber warning appears above the usual confirmation text.

tip

The Pre-Immigration count in the dialog is re-fetched when the dialog opens, so it reflects scans made at other terminals — not a stale number from the page you were looking at.

The trip's Status changes to Closed and a Set As Departed action becomes available. From here you can review the trip and its boarded passengers, then record the departure.

After closing, the trip is Closed and Set As Departed is available.

3. Set As Depart​

Setting a trip as departed is the final step. It records that the trip has left, finalizes the trip, and makes its manifest available to download or send.

Final step — cannot be changed

Marking a trip as departed finalizes it. Once departed, the trip is unchangeable and no further action can be taken on it.

Steps​

  1. Open Current Trips, select the Closed trip to open its detail page, then click Set As Depart.
  2. A confirmation appears — click Confirm.

Outcome​

The page reloads with the trip now showing the Departed status, and a Download Manifest button so you can download (or send) the trip's passenger manifest — see Passenger Manifest.

The finalized, Departed trip with its manifest ready to download.

This is the end of the trip's journey — the trip is finalized and no further action can be taken.

Related​
