Departure Trips

Departure Trips is where you view and manage all of the terminal's trips — both the Scheduled trips generated by a Trip Sync Job and one-off AdHoc trips added manually. It offers a calendar and a list view, each with a filter. By default it shows the coming week (today through the next 6 days).

Departure Trips → Calendar / List → View · Cancel · Restore · New AdHoc Trip

note

You need permission to view and manage departure trips. The screenshots below use https://ts-terminal.sindoferry.com.sg/.

Calendar and list views​

Use the Calendar / List toggle (top right) to switch views. Both are filtered by Trip Date (defaulting to the coming week) and can be narrowed further with Show Filters.

  • The Calendar (Departure Trip Calendar) lays trips out by departure time (rows) across the days of the window (columns). Each card shows the trip code, operator, route, status, and load.

    The calendar view — one week of trips, each card with a View button and a ⋯ menu.

  • The List shows one row per trip with its Date, Code, Operator, Route, Type, Departure (and gate window), Status, and passenger counts (PAX).

    The list view — note the Type column (Scheduled vs AdHoc).

1. View, cancel, and restore a trip​

Open a trip's detail​

In the calendar, click a trip card or its View button to open the trip's detail page. In the list, use the row ⋯ Actions → View Detail. The detail page shows the trip info, a status timeline (Scheduled → Boarding → Closed → Departed), the passenger list, and a Download / Cancel action.

The trip detail page — trip info, status timeline, and passengers.

Cancel or restore a trip​

The row ⋯ Actions menu (available in both the calendar and list) offers View Detail plus, depending on the trip's status, Cancel Trip or Restore Trip:

A Scheduled trip's Actions menu — View Detail and Cancel Trip.

  • Cancel Trip — available for Scheduled trips. A trip cannot be cancelled once it has checked-in passengers. Cancelling sets the trip's status to Cancelled.
  • Restore Trip — available for Cancelled trips; it returns the trip to Scheduled. A trip can only be restored while:
    • its departure time is still in the future;
    • no other active trip already uses its code; and
    • its operator, route, and vessel are all active.
tip

Restore is essentially "un-cancel", so it only appears on cancelled trips. If a restore is blocked, the message tells you why — e.g. reactivate the vessel, or the departure time has already passed.

2. Create an AdHoc trip​

An AdHoc trip is an unscheduled, one-off trip — one that isn't produced by a timeslot. Authorized users can add one directly here.

  1. Click New AdHoc Trip (top right) to open the New AdHoc Departure Trip form (route: /departure-trips/new).

  2. Fill in the form:

    FieldNotes
    OperatorThe operator running the trip.
    VesselEnabled after choosing an operator; lists only that operator's active vessels.
    RouteThe trip's route.
    Trip DateThe date of the trip (today or later).
    Code Suffix (optional)Distinguishes it from another trip that would otherwise share the same code.
    Gate Open / Gate Close / DepartureThe trip's timings (Gate Open ≤ Gate Close, and Departure after Gate Close).

  3. Click Create Trip.

Creating an AdHoc trip for Waterfront Ferry on the WFC–HFC route, departing 2:30 PM.

The AdHoc trip then appears in both the calendar and list views alongside the scheduled trips — distinguished by its Type = AdHoc badge.

The new trip in the list, tagged AdHoc (all sync-generated trips are Scheduled).

Scheduled vs AdHoc

Every trip carries a Type: Scheduled trips come from a Trip Sync Job run against your timeslots; AdHoc trips are the one-off trips you create here. A sync job only ever touches Scheduled trips — your AdHoc trips are never removed by it.
