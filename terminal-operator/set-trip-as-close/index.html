Set a Trip as Close

Closing a trip ends boarding. After it, no more passengers can be scanned aboard, and the trip is ready to be recorded as departed.

Boarding Scan (or Current Trips) → Set As Close → confirm

This cannot be undone

Closing is final. Boarding cannot be reopened, and the boarding revert stops working. Make your corrections before you close.

Before you close​

  • The trip is in Boarding status. Set As Close is not offered on a Scheduled trip — it has to be opened for boarding first.
  • Everyone who is going is aboard. Check the trip card's Pre-Imm count: anything above zero is a passenger inside the terminal who has not boarded.
  • Any last call has been made.
  • Any wrong scans have been reverted.

Where you can close a trip​

Three places, same dialog:

  1. From the Boarding Scan page — click Set As Close at the top of that trip's card in the Boarding Trips panel. This is the usual one, because it is where the gate officer already is.
  2. From the trip's detail page — open Operational → Current Trips, click the trip, then Set As Close at the top right.
  3. From the Current Trips list — the row's ⋯ menu offers Set As Close directly.

Confirm​

A dialog opens headed Set As Close, with the trip's code · date · departure time beneath it, and the text:

Close boarding for this trip. No further passengers can board afterwards, and the trip can then be departed. This moves the trip forward and cannot be undone.

The Set As Close confirmation, opened from the Boarding Scan page.

Click Set As Close to commit, or Cancel to back out.

If passengers are still in Pre-Immigration​

An amber warning appears above that text:

⚠ N passenger(s) still in Pre-Immigration They have not boarded yet. Closing this trip will prevent them from boarding.

Closing a trip that still has a passenger in Pre-Immigration — the amber warning appears above the usual confirmation text.

The warning does not block you. It is there so the closure is a deliberate decision rather than an accident. If those passengers are still expected:

  1. Click Cancel.
  2. Make a last call and board them from Boarding Scan.
  3. Close the trip afterwards.

Otherwise go ahead and close — they will be left behind.

The count in the dialog is fresh

The pre-immigration number is re-read when the dialog opens, not taken from the page you were looking at. So it reflects scans made seconds ago at another desk, not a stale figure.

Outcome​

  • The trip's status becomes Closed.
  • Set As Departed becomes available, in the same places.
  • On the Boarding Scan page the trip stays visible in the Boarding Trips panel with a Closed badge, so you can depart it without going anywhere else.
  • Any boarding scan against it is now rejected with "Trip must be in Boarding status to mark passenger as Boarded. Current status: Closed."
  • The manifest becomes downloadable from the trip's detail page under Departure Trips — see Download the Manifest.

After closing, the trip is Closed and Set As Departed is available.

Status order cannot be skipped​

On a trip that is…Set As Close is…
Schedulednot offered — set it to Boarding first
Boardingoffered
Closed / Departed / Cancellednot offered

Force it through and the system answers "Only boarding trips can be closed. Current status is …"
