Melihat Status Penumpang di Perjalanan (API)

Menampilkan semua penumpang di salah satu perjalanan Anda, beserta nomor boarding pass dan sejauh mana mereka sudah sampai — sudah check-in, sudah melewati Pre-Immigration, sudah Boarded, atau dibatalkan.

GET {API_BASE_URL}/api/Operator/Passengers/by-trip · permission operator.passenger.read

Permintaan​

Lima field perjalanan dikirim di query string — lihat Mengidentifikasi Perjalanan:

GET {API_BASE_URL}/api/Operator/Passengers/by-trip?tripType=0&routeTripCode=HW&tripDate=2026-11-02&departure=09:30:00
Authorization: Bearer {access_token}
X-Operator-Code: OP001

Tambahkan &suffix=B hanya untuk perjalanan yang kodenya diakhiri suffix.

Respons​

200 OK:

[
  { "no": "A12345678", "name": "JOHN DOE", "boardingPassNo": "K7M2Q9XR4TW8HC3P", "status": 2 },
  { "no": "E98765432", "name": "JANE ROE", "boardingPassNo": "Q4WZ8N3HD7RK2MPA", "status": 0 },
  { "no": "B55501234", "name": "ALEX TAN", "boardingPassNo": "H3CR9TW2YB6KXN4S", "status": 3 }
]
FieldCatatan
noNomor paspor / dokumen perjalanan.
nameNama lengkap.
boardingPassNoNomor boarding pass.
status0 CheckedIn, 1 PreImmigration, 2 Boarded, 3 Cancelled.
  • Semua penumpang di perjalanan itu tercantum, apa pun cara check-in-nya — melalui API ini, Operator Portal, atau terminal — termasuk yang dibatalkan.
  • Urutannya tidak dijamin. Urutkan sendiri jika perlu.
  • Perjalanan tanpa penumpang menghasilkan [].

Jika Permintaan Ditolak​

HTTPPesanArtinya
404Departure trip not found (code 'SSFHW202611020930').Tidak ada perjalanan dengan kode itu — lihat Mengidentifikasi Perjalanan.

Kegunaan Umum​

  • Memulihkan nomor boarding pass setelah respons check-in hilang: pilih baris dengan no penumpang yang status-nya bukan 3. Sebuah nomor dokumen hanya muncul lebih dari sekali jika check-in sebelumnya dibatalkan.
  • Mencocokkan pemesanan Anda dengan data yang dipegang terminal sebelum keberangkatan.
  • Memantau hari itu: 1 berarti penumpang sudah melewati Pre-Immigration, 2 berarti sudah Boarded.
