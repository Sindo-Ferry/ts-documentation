Mengunduh Manifest

Manifest adalah daftar penumpang resmi sebuah perjalanan. Ini jalur cepatnya: dua klik dari perjalanan, sebagai file Excel dalam bahasa Inggris atau Indonesia.

Departure Trips → perjalanan → Download Manifest → English / Indonesian

Butuh PDF, status penumpang lain, atau kata sandi?

Tombol ini selalu menghasilkan file Excel berisi penumpang Boarded. Untuk kebutuhan lain — PDF, semua penumpang, hanya yang dibatalkan, atau perlindungan kata sandi — gunakan Mengekspor Laporan Manifest Penumpang.

Sebelum Memulai​

  • Anda sudah masuk dengan operator yang benar terpilih — lihat Masuk.
  • Anda memiliki permission export-manifest; tanpanya tombol tidak muncul.
  • Perjalanan berstatus Closed atau Departed.

Kapan Tombolnya Berfungsi​

Closed sudah cukup — tidak perlu menunggu keberangkatan

Di portal operator, manifest terbuka segera setelah perjalanan Closed. Halaman Current Trips milik terminal menunggu Departed, jadi Anda mungkin dapat mengambil daftarnya lebih dulu daripada terminal.

Status perjalananDownload Manifest
ScheduledNonaktif, tooltip: "Available once the trip is closed or departed."
BoardingNonaktif, tooltip yang sama
ClosedAktif
DepartedAktif
CancelledNonaktif

Tombolnya nonaktif, bukan disembunyikan — jadi jika Anda sama sekali tidak melihatnya, itu masalah permission, bukan status.

Cara 1 — Dari Grid Perjalanan​

Buka Departure Trips dan temukan perjalanannya. Selnya memiliki tindakan Manifest di samping View. Klik lalu pilih bahasanya.

Manifest pada sel perjalanan Departed, dengan pilihan English dan Indonesian.

Paling cocok saat Anda mengambil manifest beberapa perjalanan berturut-turut.

Cara 2 — Dari Halaman Detail Perjalanan​

Klik View pada perjalanan, lalu Download Manifest di kanan atas halaman detail, dan pilih:

  • English
  • Indonesian

Download Manifest di kanan atas halaman detail perjalanan Departed.

Tombol bertuliskan Downloading… selama file dibuat.

Paling cocok saat Anda ingin memeriksa detail dan hitungan perjalanan sebelum mengambil daftarnya.

Yang Anda Dapat​

File Excel (.xlsx) bernama:

passenger-manifest-<TRIP-CODE>-<TRIP-DATE>.xlsx

misalnya passenger-manifest-SSFHW202607031300-2026-07-03.xlsx.

Isinya hanya penumpang Boarded, diurutkan berdasarkan jam check-in, dengan detail perjalanan serta No, nama, jenis kelamin, tanggal lahir, kewarganegaraan, negara penerbit, tanggal terbit / kedaluwarsa, nomor boarding pass, jenis penumpang, dan status setiap penumpang.

Kedua bahasa mencantumkan orang yang sama

Indonesian mengubah teks judul dan label, bukan penumpangnya. Unduh keduanya dan barisnya sama persis.

Memastikan File-nya Benar​

Manifest hanya mencantumkan penumpang Boarded. Penumpang yang sudah check-in tetapi tidak pernah naik, dan penumpang yang dibatalkan, tidak dicantumkan — jadi:

jumlah baris di file = hitungan Boarded perjalanan

Bandingkan dengan angka Boarded di halaman detail perjalanan, bukan Checked-In. File yang terlihat pendek biasanya memang benar.
