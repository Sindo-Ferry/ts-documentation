Masuk ke Operator Portal

Masuk terdiri dari dua bagian: autentikasi dengan akun Anda, lalu pilih workspace operator tempat Anda bekerja. Semua hal lain di portal — perjalanan, penumpang, manifest — dibatasi ke workspace tersebut, jadi memilihnya dengan benar itu penting.

Login → Sign In → Select Operator (Operator Code) → Dashboard

catatan

Operator Code Anda diberikan oleh administrator. Tangkapan layar di bawah menggunakan kode contoh dan https://ts-operator.sindoferry.com.sg/.

Sebelum Memulai​

  • Akun terdaftar dengan email yang sudah dikonfirmasi, dan sudah diaktifkan oleh administrator — lihat Mendaftarkan Akun.
  • Operator Code Anda.

Langkah 1 — Masuk dengan Akun Anda​

Buka Operator Portal dan masuk ke halaman login. Masukkan Email dan Password yang terdaftar, lalu klik Sign In.

Halaman masuk Operator Portal.

Langkah 2 — Pilih Operator Anda​

Layar Select Operator menanyakan workspace mana yang Anda masuki:

  • Pertama kali: ketik Operator Code Anda di kolom Enter operator code… lalu klik tombol +. Kode diverifikasi dan workspace ditambahkan ke daftar Anda.
  • Sudah pernah: operator yang sudah diverifikasi tersimpan di bawahnya. Klik kartu workspace — atau gunakan kotak search jika Anda punya beberapa — untuk melanjutkan.

Masukkan Operator Code lalu tambahkan, atau pilih workspace yang tersimpan.

Workspace tersimpan tetap ada di perangkat ini

Setelah diverifikasi, operator tetap ada di daftar sehingga Anda tidak memerlukan kodenya lagi. Setiap kartu memiliki ikon tempat sampah untuk menghapusnya — berguna jika Anda tidak lagi bekerja untuk operator tersebut. Menghapusnya tidak memengaruhi akun Anda; Anda dapat menambahkannya kembali dengan kode.

Langkah 3 — Anda Sudah Masuk​

Anda tiba di Dashboard workspace tersebut, yang menampilkan perjalanan hari ini, aktivitas Boarding, dan total penumpang. Nama dan logo operator tampil di kiri atas — selalu pastikan sesuai dengan operator tempat Anda bekerja.

Dashboard Operator Portal setelah memilih operator.

Sidebar menampilkan modul yang dapat Anda akses:

MenuKegunaannya
OverviewDashboard
VesselsMencari Vessel — read-only
TimeslotsMencari Timeslot — read-only
Departure TripsMencari perjalanan, mengganti Vessel, check-in penumpang
PassengersMencari penumpang — read-only
OperatorDetail operator Anda sendiri
ReportsMengekspor laporan Passenger Manifest
Anda hanya melihat data operator Anda sendiri

Setiap daftar di portal dibatasi ke workspace yang Anda pilih — perjalanan, penumpang, Vessel, Timeslot, serta pemilih perjalanan di dalam filter dan laporan. Data operator feri lain tidak pernah muncul. Jika Anda melihatnya, berhenti dan segera laporkan ke administrator Anda.

Pemecahan Masalah​

PesanArtinyaYang dilakukan
"Email not confirmed. Please check your inbox."Alamat email Anda belum dikonfirmasi.Gunakan tautan konfirmasi, atau Resend confirmation email jika sudah kedaluwarsa — lihat Mendaftarkan Akun.
"Login succeeded, but your account is not provisioned for Opusbay access. Please contact your administrator."Akun Anda ada tetapi belum diaktifkan.Minta administrator mengaktifkannya — lihat Mendaftarkan Akun.
Operator Code tidak diterimaKode salah, atau bukan milik Anda.Periksa dengan administrator Anda — kode berbeda untuk setiap operator.
Item sidebar yang diharapkan tidak adaAnda tidak memiliki permission untuk modul tersebut.Tanyakan ke administrator Anda.
