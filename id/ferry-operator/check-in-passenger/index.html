Check In a Passenger

Checking a passenger in records them against a trip and issues their boarding pass — the 16-character number that gets scanned at pre-immigration and the boarding gate.

Departure Trips → find the trip → View → Check In Passenger → fill in → Check In Passenger

Operators check in ordinary passengers only

There is no Passenger Type field on this form, and that is correct. NTL (Not To Land) and LM (Last Minute) passengers are a terminal-side concern — see the terminal Check In an NTL / LM Passenger guide.

Before you start​

  • You are signed in with the right operator selected — see Sign In.
  • The trip is Scheduled and its gate has not yet closed.
  • The trip has a free seat.
  • You have the passenger's travel document in hand.

Step 1 — Open the trip​

Open Departure Trips, filter to the day (set From Date and To Date to the same date for a single day), find the trip and click View.

Departure Trips filtered to a single day. Each trip cell has a View button.

Step 2 — Click Check In Passenger​

The button sits above the Passengers table on the trip detail page. Check Available in the counts first — zero means the vessel is full.

The trip detail page. Checked-in passengers appear in the Passengers table.

The button is greyed out?

Check In Passenger is enabled only while the trip is Scheduled and the gate is still open. It is disabled when:

  • the trip is Boarding, Closed, Departed or Cancelled; or
  • the trip is still Scheduled but its gate close time has already passed.

That second case surprises people: check-in closes when the gate closes, not when boarding starts. If the gate window needs extending, ask the terminal to update the trip's timings.

Step 3 — Fill in the form​

FieldNotes
NoPassport / ID number. Letters and digits only — no dashes, slashes or spaces. At least 3 characters.
NameFull name. Letters, digits and spaces only. At least 2 characters.
GenderMale, Female or Unspecified.
NationalityRequired. Pick from the country list.
Date of BirthRequired. Must be in the past.
Issue Date (optional)The only optional field. Cannot be in the future.
Expiry DateRequired. Cannot be in the past — the earliest selectable date is today.
Issue CountryRequired.

Then click Check In Passenger.

The Check In Passenger form.

Step 4 — Print the boarding pass​

If you hold the boarding-pass permission, a prompt appears immediately:

Passenger Checked In — Print the boarding pass now?

The print prompt, with the new passenger already in the table behind it.

Click Print Boarding Pass, or Not Now to print later from the passenger's row — see Reprint or Download a Boarding Pass.

Outcome​

  • The passenger appears in the trip's table with status CheckedIn.
  • A unique 16-character boarding pass number is issued.
  • The trip's Checked-In count and Load go up; Available goes down.

If the check-in is rejected​

MessageWhat it meansWhat to do
"No must contain only letters and digits. Invalid character(s): '-', '/'"The document number contains symbols. The message names them.Strip them — A-12/3 becomes A123.
"Name must contain only letters, digits, and spaces. Invalid character(s): …"The name contains punctuation.Remove apostrophes, hyphens and accents.
"A passenger with this No already exists on this trip."That document number is already checked in on this sailing.Check the passenger table — it may be a genuine duplicate. Cancelled passengers are ignored, so a cancelled record does not block re-use.
"No available seats on this trip."The vessel is full.Another sailing, or cancel a no-show to free a seat.
"Issue date must be before the expiry date."Issue Date is on or after Expiry Date.Re-read the document.
"Date of birth must be before the issue date."Date of Birth is on or after Issue Date.Re-read the document.
A field is flagged individuallyA required field is empty.Everything except Issue Date is required.

Checking in a passenger whose No is already on the trip is rejected.

Correcting or cancelling a check-in​

Both are done from the ⋯ Actions menu at the end of the passenger's row in the trip's table.

The row Actions menu: View, Edit, and Cancel Passenger.

Edit the details​

Choose Edit Passenger. The dialog opens pre-filled with the current details — No, Full Name, Gender, Date of Birth, Expiry Date, Nationality, Issue Country, Issue Date. Correct what you need and click Save Changes.

The Edit Passenger dialog, pre-filled with the passenger's details.

The same validation applies, including the duplicate-No check. Editing does not change the boarding pass number — but reprint the pass if the printed name has changed.

Editing stops once the passenger is scanned

Only a CheckedIn passenger can be edited. Once the terminal scans them through pre-immigration, their details are locked — the record has been checked against their passport at that point. Ask the terminal if a correction is genuinely needed.

Cancel the check-in​

Choose Cancel Passenger (the red option) and confirm with Confirm Cancel.

Confirm before cancelling the passenger's check-in.

The passenger's status becomes Cancelled, the seat is released, and the row stays in the table for reference. The record is not deleted.

After confirming, the passenger's status shows Cancelled and the seat is freed.

Cancel then re-check-in is the fix for a badly wrong record

The duplicate-No check ignores cancelled passengers, so cancelling a mis-keyed record and checking in again with the same document number works. Note that this issues a new boarding pass number — the old printout is no longer valid.
