Look Up a Passenger

The Passengers page is a quick way to find a passenger on an upcoming sailing without knowing which trip they are on.

Passengers → search / filter → ⋯ → View Passenger

Read-only

You can search, filter and open a passenger's record. You cannot check in, edit, cancel or print from here — the row ⋯ menu offers only View Passenger.

Those actions live on the trip's own detail page — see Check In a Passenger.

The screenshots below use https://ts-operator.sindoferry.com.sg/.

Before you start​

  • You are signed in with the right operator selected — see Sign In.

Step 1 — Open Passengers​

In the sidebar, open Passengers (route: /passengers).

Each row shows the passenger's Trip (code, with trip date and departure beneath), No (passport / ID), Name, Type, Status and Nationality.

The Passengers list — Trip, No, Name, Type, Status, and Nationality.

Step 2 — Know what this page covers​

Scheduled trips only, and today by default — the two things that catch people out

This page has two filters applied before you type anything:

  1. Trip date = today. Widen Show Filters → trip date to reach other days.
  2. Trip status = Scheduled. Passengers whose trip has moved on to Boarding, Closed, Departed or Cancelled stop appearing here — and widening the date range will not bring them back.

So a passenger who sailed this morning is genuinely not findable on this page. That is by design: it is a view of sailings that have not yet gone.

To find someone on a trip that has already started or sailed, go through the trip instead: Departure Trips → find the trip → View. The trip detail page lists every passenger with their final status, whatever the trip's status.

Step 3 — Search and filter​

  • Search box — a partial match on the passenger's No or Name.
  • Show Filters — narrow by trip date, No, Name, Date of Birth, Passenger Status, Route and Nationality.
  • Applied filters show as chips below the search box; remove one, or Reset to clear them all.
Empty result? Read the chips first

Between the date default and the Scheduled-only rule, an empty list usually means the passenger is outside the window rather than absent. Check the chips before concluding the record does not exist.

Step 4 — View the full record​

The row ⋯ Actions menu offers one action — View Passenger — which opens a read-only page in three sections:

SectionWhat it contains
Trips InformationsTrip Code, Trip Date / Departure, Trip Status, Trip Type, Route, Vessel
Passport InformationsNo, Name, Gender, Date of Birth, Issuance Date, Nationality, Issuance Country, Passport Expiry Date
Check In InformationsBoarding Pass No, Type, Status, Checked-in At, Pre-Immigration At, Boarded At, and whether the passenger was Cancelled

The View Passenger page — trip, passport, and check-in details.

The Check In Informations timestamps show how far the passenger got: a Boarded At time means they were scanned aboard.

Which page to use​

You want to…Go to
Find a passenger on an upcoming trip, trip unknownThis page
See everyone on a specific trip, any statusLook Up a Trip → View
Check in, edit or cancelCheck In a Passenger
