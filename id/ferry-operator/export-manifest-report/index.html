Mengekspor Laporan Manifest Penumpang

Laporan Passenger Manifest adalah versi manifest dengan pilihan lengkap. Jika tombol Download Manifest di halaman perjalanan selalu memberi file Excel berisi penumpang Boarded, formulir ini memungkinkan Anda memilih format, bahasa, penumpang mana yang dicantumkan, dan apakah hasilnya dilindungi kata sandi.

Reports → Passenger Manifest → pilih perjalanan dan opsinya → Download Report

catatan

Anda membutuhkan permission manifest-report; tanpanya item Reports tidak muncul di sidebar. Tangkapan layar di bawah menggunakan https://ts-operator.sindoferry.com.sg/.

Sebelum Memulai​

  • Anda sudah masuk dengan operator yang benar terpilih — lihat Masuk.
  • Anda tahu perjalanan mana yang diinginkan. Pemilihnya hanya menampilkan perjalanan milik Anda.

Langkah 1 — Buka Laporannya​

Di sidebar, buka Reports (route: /reports). Halaman ini menampilkan laporan yang dapat Anda akses; klik Passenger Manifest — "Boarding / passenger list for a departure trip."

Halaman Reports, dengan kartu Passenger Manifest.

Jika daftarnya bertuliskan "You don't have access to any reports," tanyakan ke administrator Anda.

Langkah 2 — Isi Formulir​

KolomPilihanDefault
Departure TripKlik Select trip dan pilih dari perjalanan operator Anda. Wajib.—
FormatExcel (.xlsx) atau PDF (.pdf)Excel
LanguageEnglish atau IndonesianEnglish
Passenger StatusAll passengers, atau salah satu dari CheckedIn, PreImmigration, Boarded, CancelledBoarded
Password (optional)Melindungi file yang dibuat. Hanya muncul jika Format = PDF.kosong

Formulir dengan perjalanan terpilih dan nilai default — Excel (.xlsx), English, Boarded. Kolom Password tidak tampil karena formatnya Excel.

Lalu klik Download Report. Tombol bertuliskan Generating… selama prosesnya berjalan.

Memilih Status Penumpang​

Pengaturan inilah yang membuat laporan ini berguna:

StatusYang Anda dapatPenggunaan umum
Boarded (default)Hanya penumpang yang sudah dipindai naik.Manifest resmi siapa yang berlayar.
All passengersSemua orang di perjalanan, apa pun statusnya.Mencocokkan pemesanan dengan yang benar-benar berangkat.
CheckedInSudah check-in tetapi tidak naik.Menelusuri penumpang yang tidak datang setelah keberangkatan.
PreImmigrationSudah melewati Pre-Immigration tetapi tidak pernah naik.Menyelidiki penumpang yang tertinggal.
CancelledHanya pemesanan yang dibatalkan.Pengembalian dana dan catatan pembatalan.
Default-nya Boarded, bukan semua orang

Jika formulir tidak diubah, Anda hanya mendapat penumpang Boarded — sama dengan tombol Download Manifest di perjalanan. Jika butuh daftar lengkap, Anda harus mengubah Passenger Status menjadi All passengers.

Perlindungan Kata Sandi​

Kata sandi hanya untuk PDF

Kolom Password (optional) hanya muncul jika Format = PDF. Ubah format ke Excel dan kolom itu hilang — hasil Excel tidak dapat dilindungi kata sandi di sini, dan layanan ekspor menolak percobaannya.

Petunjuk di kolom itu sendiri menyebutkannya: "Protects the generated PDF. Only available for the PDF format."

Untuk melindungi laporan:

  1. Atur Format ke PDF (.pdf).
  2. Ketik kata sandi di Password (optional) — tersamarkan saat diketik.
  3. Download Report. File akan meminta kata sandi tersebut saat dibuka.

Kosongkan dan PDF terbuka seperti biasa.

Kata sandi tidak disimpan di mana pun

Tidak ada yang mencatat apa yang Anda ketik. Jika Anda mengirim manifest yang dilindungi, sampaikan kata sandinya kepada penerima melalui saluran terpisah — dan simpan catatan Anda sendiri. Membuat ulang laporan dengan kata sandi yang sama adalah satu-satunya jalan kembali.

Yang Anda Dapat​

File bernama:

passenger-manifest-<TRIP-CODE>-<TRIP-DATE>.pdf   (atau .xlsx)

Ekstensinya mengikuti Format yang Anda pilih. Isinya sama dalam kedua format — detail perjalanan ditambah satu baris per penumpang yang sesuai filter status Anda.

Laporan Ini vs. Tombol Download Manifest di Perjalanan​

Download Manifest (di perjalanan)Laporan Passenger Manifest
TempatGrid Departure Trips atau detail perjalananReports → Passenger Manifest
FormatHanya ExcelExcel atau PDF
BahasaEnglish / IndonesianEnglish / Indonesian
PenumpangHanya BoardedStatus apa pun, atau semua
Kata sandiTidakYa, pada PDF
Perjalanan harusClosed atau DepartedDipilih dari pemilih
KecepatanDua klikFormulir singkat

Gunakan tombol untuk manifest sehari-hari; gunakan laporan saat Anda membutuhkan format lain, kumpulan penumpang lain, atau perlindungan.

Hanya Data Operator Anda Sendiri​

Pemilih Departure Trip hanya menampilkan perjalanan operator Anda, dan file yang dibuat hanya berisi penumpang Anda sendiri. Totalnya harus cocok persis dengan tabel penumpang perjalanan.

Perjalanan atau penumpang operator lain yang muncul di sini adalah masalah serius — berhenti dan laporkan ke administrator Anda.
