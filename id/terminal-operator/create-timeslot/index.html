Create a Timeslot

A timeslot is a line in the recurring weekly schedule. It says: this operator, on this route, with this vessel, departs at this time, on these days.

Timeslots are templates, not trips. Nothing sails because a timeslot exists — the timeslot is what the system reads when it generates trips for a date.

Timeslots → Create Timeslot → fill in the form → Create Timeslot

catatan

You need permission to manage timeslots. The screenshots below use https://ts-terminal.sindoferry.com.sg/.

Before you start​

  • You are signed in to the Terminal Portal — see Sign In to the Terminal Portal.
  • The operator, the route, and an active vessel belonging to that operator already exist. A timeslot is where those three come together, so if any of them is missing you cannot finish the form.
  • If the sailing runs on holidays, the relevant public holidays are already configured. You pick countries here, not dates — so the dates have to exist first.

Step 1 — Open Timeslots​

In the sidebar, open Management → Timeslots (route: /departure-timeslots).

You land on either the Calendar or the List view — use the Calendar / List toggle at the top right to switch. Both views describe the same timeslots; see Check your work below.

Step 2 — Click Create Timeslot and fill in the form​

Click Create Timeslot and complete each field:

FieldWhat to enter
OperatorThe ferry operator running the service (e.g. Waterfront Ferry).
RouteThe route it sails (e.g. WFC - TMFT — Waterfront to Tanah Merah).
Default VesselThe vessel to assign. This picker stays disabled until you pick an operator, and then lists only that operator's vessels.
Gate Open / Gate Close / DepartureThe three times for the sailing — e.g. gate open 10:40, gate close 11:10, depart 11:20 AM.
Suffix (optional)Only needed when two timeslots would otherwise be identical — see the warning below.
DaysTick Weekday, Weekend, Public Holiday, or individual days. All Days ticks everything at once.
Public Holiday countriesAppears only once Public Holiday is ticked. Click Select countries, tick the countries whose public holidays this sailing runs on (the header checkbox ticks the whole page), then Done. The countries you picked appear as chips you can remove one by one.
ActiveTicked by default. Only active timeslots generate trips.

Then click Create Timeslot.

Creating a Waterfront Ferry timeslot on WFC - TMFT, departing 11:20 AM — running Monday–Friday and additionally on ID and SG public holidays, shown as removable chips.

Step 3 — If the save is rejected​

The system checks four things before it saves. If one fails, fix it and save again:

Message you may seeWhat it means
Times are out of orderGate Open must be at or before Gate Close, which must be at or before Departure.
The vessel is not validThe Default Vessel must belong to the operator you picked and must be active.
A timeslot with this code already existsTwo timeslots sharing the same operator, route and departure time must have a different Suffix — otherwise they would generate two trips with the same code.
Public Holiday needs a countryYou ticked Public Holiday but picked no countries. Pick at least one, or untick the flag.

Step 4 — Check your work​

The new timeslot appears in both views. Each view has its own filter (operator, route, status, and — in the list — day).

Calendar view​

The Departure Timeslot Weekly Grid lays timeslots out by departure time (rows) across the days of the week (columns), with PH as the last column. Each card shows the operator, route, vessel and Active/Inactive status; in the PH column the card also carries a small tag with the holiday country codes. An empty cell shows + Add, which creates a timeslot for that time and day.

  • Click a card to select the whole timeslot — every day it runs on lights up together, which is the quickest way to see one schedule as a single thing.
  • Double-click a card to edit it.

Selecting the 07:00 timeslot highlights every day it runs on as one group — Mon–Sun and the PH column, whose card carries its ID and SG tags.

List view​

One row per timeslot, showing the operator (with day badges), route, vessel, departure (with the gate open–close window), and status. A timeslot that runs on holidays shows its countries in the badge — e.g. Public Holiday (ID, SG). No badge means it does not run on holidays.

The list view, filtered to Harbourfront to Waterfront — each row's day badges show Weekday, Weekend, and where applicable Public Holiday with its country codes.

Step 5 — Change a timeslot later​

From the row ⋯ Actions menu in the list view:

  • Edit — reopen the form.
  • Activate / Deactivate — turn the timeslot on or off for trip generation. A deactivated timeslot stops producing new trips; trips it already produced are unaffected until the next generation run.
  • Delete — remove it entirely.

The Actions menu — Edit, Deactivate, and Delete.

A timeslot can only be activated while its vessel is active

If the default vessel has been deactivated, you cannot reactivate the timeslot. Reactivate the vessel first, or point the timeslot at a different one.

How days actually work​

This trips people up, so it is worth being precise. The day rule is additive — a public holiday adds sailings, it never removes the ordinary weekday ones.

On a given date…A timeslot runs when…
any dateits weekday flag for that day of the week is ticked
the date is also a public holiday in country Xadditionally, its Public Holiday countries include X

So with a Singapore holiday falling on a Monday:

  • every timeslot with Monday ticked runs as normal;
  • a Public Holiday (SG) timeslot runs as well — an extra sailing that day;
  • a Public Holiday (ID)-only timeslot does not, because the date is not an Indonesian holiday;
  • a timeslot with both Monday and Public Holiday (SG) ticked still generates only one trip that day.
