Download the Manifest

The manifest is the official list of who actually sailed. It is an Excel file, available in English or Indonesian, and it lists Boarded passengers only.

Open the trip → Download Manifest → English / Indonesian

What is on it​

Only passengers whose final status is Boarded, ordered by check-in time. Passengers who were checked in but never boarded, and passengers who were cancelled, are left out. The number of rows equals the trip's Boarded count.

For each passenger the file carries the trip details (code, date, departure, route, vessel) plus the passenger's No, name, gender, date of birth, nationality, issue country, issue / expiry dates, boarding pass number, passenger type and status.

Both languages list the same people

Choosing Indonesian changes the wording of the headings and labels, not the passengers. Download both and the rows match line for line.

Where to find the button — and when it works​

This catches people out, because the two pages behave differently.

Where you areDownload Manifest appears when the trip is…
Operational → Current Trips → trip detailDeparted only
Management → Departure Trips → trip detailClosed or Departed
Management → Departure Trips → list view, row ⋯ menuClosed or Departed

So: on Current Trips the button is absent on Scheduled, Boarding and Closed trips, and appears only once the trip has Departed. If you need the manifest for a trip that is Closed but not yet departed, go to Departure Trips instead — that page allows it as soon as the trip is closed.

On the Departure Trips detail page the button is visible but greyed out on a Scheduled or Boarding trip, with a tooltip explaining why:

  • "Available once the trip is closed or departed." — the trip is still Scheduled or Boarding.
  • "Select a trip to download its manifest." — no trip is loaded.

In the Departure Trips list, the Download Manifest item simply is not in the row menu for a Scheduled or Boarding trip.

Method 1 — From the trip's detail page​

  1. Open the trip — Current Trips (if Departed) or Departure Trips (if Closed or Departed).
  2. Click Download Manifest at the top right.
  3. Choose English or Indonesian.

A Departed trip. Download Manifest is enabled at the top right.

Pick the language — the report is generated in that language.

The button reads Downloading… while the file is being generated.

Method 2 — From the Departure Trips list​

Best for an older trip, because you never have to open it.

  1. Open Management → Departure Trips and switch to the List view.
  2. Filter Trip Date to the day you want.
  3. On a Closed or Departed row, open the ⋯ menu → Download Manifest → English or Indonesian.

The menu item reads Downloading Manifest… while it works.

The file​

An Excel (.xlsx) file named:

passenger-manifest-<TRIP-CODE>-<TRIP-DATE>.xlsx

for example passenger-manifest-SSFHW202607031300-2026-07-03.xlsx.

Download it as often as you like

There is no limit and no state change. As long as the trip stays Closed or Departed you can download it again, in either language. Nothing is marked as "already downloaded".

Troubleshooting​

ProblemCauseFix
No Download Manifest button on Current TripsThe trip has not departedSet it as departed, or use Departure Trips if it is merely Closed
The button is greyed outThe trip is Scheduled or BoardingHover for the tooltip; close the trip first
No button anywhere, on a departed tripYou lack the export-manifest permissionAsk your administrator
Fewer rows than expectedThe manifest lists Boarded passengers onlyCompare against the trip's Boarded count, not Checked-In — or use the Passenger Manifest report to pick another status
"The manifest was generated but could not be saved. Please try again."The browser could not write the fileCheck your downloads folder and browser download settings, then retry
