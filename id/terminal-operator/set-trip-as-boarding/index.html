Mengatur Perjalanan menjadi Boarding

Mengatur perjalanan menjadi Boarding adalah saat operasional hari itu dimulai untuk pelayaran tersebut. Tindakan ini melakukan dua hal sekaligus: membuka Boarding, dan menetapkan Gate dan Berth tujuan penumpang.

Current Trips → buka perjalanan → Set As Boarding → pilih Gate & Berth → konfirmasi

Status perjalanan hanya bergerak maju

Scheduled → Boarding → Closed → Departed (atau Cancelled). Setiap tindakan hanya tersedia pada status yang tepat, dan tidak ada yang dapat dibatalkan. Set As Boarding hanya tersedia pada perjalanan Scheduled.

catatan

Anda membutuhkan permission untuk melihat Current Trips dan menetapkan perjalanan ke Boarding. Tangkapan layar di bawah menggunakan https://ts-terminal.sindoferry.com.sg/.

Sebelum Memulai​

  • Anda sudah masuk ke Terminal Portal — lihat Masuk ke Terminal Portal.
  • Anda sudah mengatur Port aktif. Current Trips hanya menampilkan perjalanan hari ini di Port aktif Anda, jadi jika daftarnya kosong atau tampak salah, periksa Port terlebih dahulu.
  • Gate dan Berth yang akan dipakai ada di Port tersebut dan berstatus Active.

Langkah 1 — Buka Current Trips dan Pilih Perjalanan​

Di sidebar, buka Operational → Current Trips (route: /current-departure-trips). Halaman ini menampilkan perjalanan keberangkatan hari ini beserta Vessel, tujuan, jam keberangkatan, status, dan jumlah penumpang terkini.

Klik baris perjalanan untuk membuka halaman detail-nya.

Daftar Current Departure Trips — perjalanan hari ini di Port aktif Anda.

Langkah 2 — Klik Set As Boarding​

Di halaman detail perjalanan, selama Status masih Scheduled, klik Set As Boarding di kanan atas. Sebelum ditetapkan, kolom Gate / Berth berisi - / -.

Perjalanan Scheduled. Tombol Set As Boarding ada di kanan atas.

Bisa juga tanpa membuka perjalanan

Menu ⋯ pada baris perjalanan di daftar Current Trips langsung menawarkan Set As Boarding. Dialognya sama.

Langkah 3 — Pilih Gate dan Berth​

Dialog terbuka: Set As Boarding — Assign a gate and berth for [kode perjalanan] to begin boarding.

  1. Klik Gate dan pilih dari daftar Select active gate.
  2. Klik Berth dan pilih dengan cara yang sama.
  3. Klik Set As Boarding untuk mengonfirmasi.

Dialog Set As Boarding — pilih Gate dan Berth, lalu konfirmasi.

Pemilih Gate menampilkan Gate aktif di Port asal perjalanan; pemilih Berth bekerja dengan cara yang sama.

Keduanya wajib

Tombol konfirmasi tetap nonaktif sampai Gate dan Berth sama-sama dipilih. Anda tidak dapat membuka Boarding tanpa keduanya.

Jika Gate atau Berth yang diinginkan tidak muncul

Pemilih hanya menampilkan Gate dan Berth yang Active dan berada di Port asal perjalanan. Jika yang Anda cari tidak ada, periksa di Gates atau Berths — kemungkinan statusnya inactive, atau terdaftar di Port lain.

Langkah 4 — Hasil​

Status perjalanan berubah menjadi Boarding, Gate dan Berth tersimpan pada perjalanan, dan muncul pertanyaan:

Trip Set As Boarding — Open the Boarding Scan page now?

Pilih Open Boarding Scan untuk membuka halaman Boarding Scan di tab baru, atau Not Now jika rekan lain di Gate sudah menjalankannya.

Sejak saat ini perjalanan sudah aktif:

  • Perjalanan muncul di panel Boarding Trips pada Boarding Scan, tempat petugas Gate memindai penumpang naik ke kapal.
  • Penumpang masih dapat melewati Pre-Immigration — dan setelah perjalanan berstatus Boarding, rentang Gate dibuka / ditutup tidak lagi membatasi pemindaian Pre-Immigration.
  • Anda masih dapat melakukan check-in penumpang NTL / LM dan mengubah waktunya.
  • Setelah Boarding selesai, tutup perjalanan.

Selanjutnya​

  • Boarding Scan — naikkan penumpang ke kapal.
  • Mengubah Waktu — sesuaikan waktu Gate atau catat keterlambatan.
  • Mengatur Perjalanan menjadi Close
