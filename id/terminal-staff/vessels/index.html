Vessels

Modul Vessels adalah tempat staf mengelola kapal feri (Vessel) yang dipakai untuk perjalanan keberangkatan. Di sini Anda dapat mencari Vessel yang ada, membuat yang baru, serta mengaktifkan, menonaktifkan, mengubah, atau menghapus Vessel.

Vessels → List View / Create Vessel → Actions (Activate · Edit · Delete)

catatan

Anda membutuhkan permission untuk mengelola Vessel. Tangkapan layar di bawah menggunakan https://ts-terminal.sindoferry.com.sg/.

Persyaratan​

  • Anda sudah masuk ke Terminal Portal — lihat Masuk ke Terminal Portal.
  • Anda memiliki permission untuk mengelola Vessel.
  • Operator pemilik Vessel sudah ada.

Daftar Vessels​

Buka Vessels (route: /vessels). Setiap baris menampilkan Code, Name, Operator, Capacity, dan Status (Active / Inactive) Vessel, serta menu Actions (⋯).

Daftar Vessels — dapat diurutkan berdasarkan Code, Name, dan Capacity.

Mencari dan Memfilter​

  • Pencarian cepat — ketik di kotak search untuk menemukan Vessel sambil mengetik.
  • Show Filters — buka dialog Filter Vessels untuk mempersempit hasil berdasarkan Operator dan Status (All Statuses, Active Only, atau Inactive Only).
  • Filter yang diterapkan tampil sebagai chip; hapus chip atau klik Reset untuk mengosongkannya. Refresh memuat ulang hasil.

Membuat Vessel​

  1. Klik Create Vessel (kanan atas) untuk membuka formulir New Vessel.

  2. Isi kolom-kolomnya:

    KolomCatatan
    OperatorPilih operator pemilik Vessel (misalnya Waterfront Ferry).
    Vessel codeKode pendek, misalnya WF-01.
    Vessel nameNama Vessel, misalnya Waterfront Star.
    Certification numberNomor sertifikasi Vessel, misalnya CERT-WF-001.
    CapacityJumlah penumpang maksimum (harus lebih dari 0).

  3. Klik Create Vessel.

Membuat Vessel untuk operator Waterfront Ferry.

Mengaktifkan Vessel​

Vessel baru berstatus Inactive

Vessel yang baru dibuat berstatus Inactive dan tidak dapat dipakai untuk perjalanan keberangkatan sampai diaktifkan.

Untuk mengaktifkan (atau menonaktifkan) Vessel, buka menu ⋯ Actions pada daftar dan pilih:

  • Activate — muncul jika Vessel berstatus Inactive; membuatnya bisa dipakai.
  • Deactivate — muncul jika Vessel berstatus Active.

Vessel WF-01 yang baru dibuat berstatus Inactive; menu ⋯-nya menawarkan Activate.

Menonaktifkan ada pengamannya

Vessel yang sudah dipakai di satu atau lebih perjalanan terjadwal tidak dapat dinonaktifkan. Pindahkan perjalanan tersebut ke Vessel lain terlebih dahulu, lalu nonaktifkan.

Mengubah atau Menghapus Vessel​

Dari menu ⋯ Actions yang sama:

  • Edit — membuka formulir Vessel untuk mengubah operator, kode, nama, nomor sertifikasi, atau kapasitasnya.
  • Delete — menghapus Vessel secara permanen. Dialog konfirmasi muncul ("Are you sure you want to delete …? This action cannot be undone."); klik Delete untuk mengonfirmasi.
