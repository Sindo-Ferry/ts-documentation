Administrator

Security administration for the Terminal Portal — build roles, give them permissions, create users, and control who can do what.

📄️Add new role

Create a security role in the Terminal Portal — the named bundle of permissions you then assign to users.

📄️Manage role's permissions

Add and remove permissions on a role using the two-panel Available / Assigned lists.

📄️Edit / delete role

Rename a role, or delete it permanently with the type-the-name confirmation.

📄️Add new user

Create a portal user for terminal staff, and understand how it connects to their sign-in account.

📄️Activate / deactivate a user

Switch a portal user between Active and Inactive — the on/off switch for portal access.

📄️Grant / revoke admin role

Give a user administrator status — full access that bypasses roles and permissions — or take it away.

📄️Assign role to a user

Give a user one or more roles, revoke them, and check the resulting effective access.

📄️Manage user's direct permissions

Grant or revoke individual permissions on one user, on top of whatever their roles give them.

📄️Delete user

Permanently remove a portal user — why it requires deactivating them first, and why deactivating is usually the better answer.
