Memberikan atau Mencabut Role Admin

Tanda Admin bukan role. Ini adalah pengecualian yang memberi pengguna akses penuh ke semua hal, sepenuhnya mengabaikan role dan permission-nya.

Users → ⋯ → Grant Admin / Revoke Admin → konfirmasi

Permission yang dibutuhkan: operator.security.is_super_admin

Admin melewati setiap pemeriksaan permission

Konfirmasinya menyebutkan dengan jelas: memberi admin memberikan pengguna "full access to all system features, bypassing standard role restrictions."

Tidak ada pengaturan role atau permission langsung yang membatasi Admin. Berikan hanya kepada yang benar-benar perlu mengelola portal — bukan sebagai jalan pintas saat role sulit diatur dengan tepat.

catatan

Anda membutuhkan permission di atas. Tangkapan layar di bawah menggunakan https://ts-operator.sindoferry.com.sg/.

Sebelum Memulai​

  • Anda sudah masuk ke Operator Portal — lihat Masuk ke Operator Portal.
  • Anda adalah Super Admin. Administrator biasa melihat item menunya dalam keadaan nonaktif.

Langkah 1 — Temukan Pengguna​

Buka Users. Administrator yang sudah ada memiliki badge Admin di kolom Status; pemilik sistem memiliki badge kuning Super Admin.

Difilter ke Account Type: Admin — seorang Admin, dan pemilik sistem dengan Admin dan Super Admin.

Langkah 2 — Berikan atau Cabut​

Dua cara, dialog yang sama:

  • Dari daftar — menu ⋯ pada baris → Grant Admin atau Revoke Admin.
  • Dari profil pengguna — ⋯ → Manage Security membuka User Security Profile, yang menampilkan Admin Access: Enabled / Disabled dan tombol Grant Admin / Revoke Admin yang sesuai. Tombol ini nonaktif di profil Super Admin sendiri.

Pengguna yang bukan Admin — menunya menawarkan Grant Admin.

Seorang Admin (perhatikan badge Admin) — item yang sama bertuliskan Revoke Admin.

Langkah 3 — Konfirmasi​

Memberikan:

Grant Administrator Privileges? — This will grant [username] full access to all system features, bypassing standard role restrictions.

Mencabut:

Revoke Administrator Privileges? — This will remove administrative overrides for [username]. They will revert to standard role-based access.

Klik Confirm Grant / Confirm Revoke (atau Cancel untuk membatalkan).

Yang Berubah​

MemberikanMencabut
AksesSemuanya, langsungKembali ke role dan permission langsungnya
RoleTidak disentuh — tetap ada, hanya tidak berpengaruh selama AdminKembali berlaku
BadgeAdmin muncul di barisnyaHilang
Mencabut bisa membuat seseorang tanpa akses sama sekali

Pengguna yang dijadikan Admin sebelum diberi role tidak memiliki akses dasar sama sekali. Cabut tandanya dan ia kembali ke nol — bisa masuk tetapi hampir tidak melihat apa pun.

Sebelum mencabut, buka tab Roles-nya dan pastikan ada yang menjadi sandarannya. Lihat Memberikan Role kepada Pengguna.

Admin vs. Super Admin​

AdminSuper Admin
FungsinyaAkses penuh ke fitur portalAkses penuh ditambah kontrol keamanan — permission role, role pengguna, permission langsung, dan pemberian admin
Cara mengaturnyaDiberikan di sini oleh Super AdminTidak dapat diatur dari portal
Dapat dicabutYaTidak — "Super Admin's administrator priviledges cannot be revoked."
Dapat dinonaktifkanYaTidak
Dapat dihapusYa, setelah tidak aktifTidak

Super Admin adalah akun pemilik sistem. Akun ini ada agar portal tidak pernah terkunci dari administrasinya sendiri, dan karena itu tidak ada tindakan merusak yang berlaku padanya.

Mengapa halaman keamanan membutuhkan Super Admin

Permission role, role pengguna, dan permission langsung semuanya mengunci tombol tindakannya untuk Super Admin — sehingga Admin biasa dapat menjalankan portal tetapi tidak dapat diam-diam memperluas aksesnya sendiri.
