Menghapus Pengguna

Menghapus pengguna mengeluarkannya dari portal secara permanen. Ada dua pengaman: pengguna harus tidak aktif terlebih dahulu, dan Anda harus mengetik username-nya untuk mengonfirmasi.

Users → ⋯ → Delete User → ketik username → Confirm Delete

Permission yang dibutuhkan: operator.users.write

Pertimbangkan menonaktifkan saja

Menonaktifkan memblokir akses seketika, dapat dikembalikan, dan menyimpan role, permission, serta riwayat orang tersebut untuk audit.

Menghapus bersifat permanen dan tidak dapat dibatalkan dari portal. Untuk orang yang sudah keluar, menonaktifkan hampir selalu jawaban yang tepat — Anda tidak kehilangan apa pun dengan menyimpan datanya.

catatan

Anda membutuhkan permission di atas. Tangkapan layar di bawah menggunakan https://ts-operator.sindoferry.com.sg/.

Sebelum Memulai​

  • Anda sudah masuk ke Operator Portal — lihat Masuk ke Operator Portal.
  • Pengguna sudah Inactive — lihat Mengaktifkan atau Menonaktifkan Pengguna. Pengguna aktif tidak dapat dihapus.
  • Anda memiliki operator.users.write.

Langkah 1 — Nonaktifkan Terlebih Dahulu​

Buka Users, temukan penggunanya, dan gunakan ⋯ → Set Inactive. Badge berubah menjadi Inactive.

Set Inactive di menu ⋯ pengguna.

Untuk langkah ini Anda mungkin membutuhkan Super Admin

Di Operator Portal, menghapus hanya membutuhkan operator.users.write — tetapi menonaktifkan membutuhkan Super Admin. Jika Anda bisa menghapus tetapi tidak bisa menonaktifkan, minta Super Admin menonaktifkan penggunanya terlebih dahulu, lalu kembali dan hapus.

Lewati langkah ini dan penghapusan akan ditolak — lihat di bawah.

Urutan dua langkah adalah pengamannya

Mewajibkan penonaktifan lebih dulu berarti tidak ada yang dapat menghapus akun aktif dengan sekali klik. Ini juga memberi jeda: setelah dinonaktifkan, aksesnya sudah hilang, jadi jarang ada urgensi untuk menghapusnya.

Langkah 2 — Hapus​

  1. Buka menu ⋯ pada baris → Delete User (berwarna merah).
  2. Dialog Delete User Account? meminta Anda mengetik username: "Type "username" to confirm deletion. This action cannot be reversed."
  3. Ketik username persis. Confirm Delete tetap nonaktif sampai cocok, termasuk huruf besarnya.
  4. Klik Confirm Delete.

Delete User Account? dengan username sudah diketik. Pengguna di gambar ini masih Active, jadi konfirmasi akan ditolak — nonaktifkan terlebih dahulu.

Jika Penghapusan Ditolak​

PesanArtinyaYang dilakukan
"Active users cannot be deleted. Please set the user as inactive before deletion."Pengguna masih Active.Nonaktifkan, lalu hapus.
"The super admin account cannot be deleted."Anda mencoba menghapus akun pemilik sistem.Tidak mungkin, memang dirancang begitu.

Apa yang Dilakukan dan Tidak Dilakukan Penghapusan​

Pengguna portal dihapusIa hilang dari daftar Users dan tidak dapat lagi diberi role atau permission.
Akun masuknya tidak disentuhAkun email-dan-password yang dibuat saat pendaftaran terpisah dan tetap ada. Ia masih bisa masuk dan akan diberi tahu bahwa akunnya belum disiapkan.
Riwayat auditTindakan yang pernah dilakukannya tercatat atas username-nya. Menghapus pengguna tidak menulis ulang riwayat itu.
Portal lain tidak terpengaruhData pengguna di portal lain terpisah dan tetap ada.
Menghapus tidak mencabut akun masuknya

Karena kedua akun terpisah, menghapus pengguna portal hanya menghilangkan aksesnya ke portal ini. Jika yang dikhawatirkan adalah akun orang itu sendiri, bukan akses portalnya, sampaikan ke tim pengembang.

Memilih di Antara Pilihan yang Ada​

SituasiLakukan ini
Seseorang sudah keluarNonaktifkan. Jejak audit tetap tersimpan.
Seseorang diskors atau sedang diselidikiNonaktifkan. Langsung berlaku dan dapat dikembalikan.
Seseorang berganti pekerjaanBiarkan aktif, ubah role-nya.
Data ganda karena kesalahan, tidak pernah dipakaiNonaktifkan, lalu hapus.
Akun uji cobaNonaktifkan, lalu hapus.

Ringkasnya: hapus adalah untuk data yang seharusnya tidak pernah ada. Untuk orang sungguhan yang sudah pindah, nonaktifkan.
