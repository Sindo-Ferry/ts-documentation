**Gate** adalah pintu Boarding di sebuah Port. Saat perjalanan diatur menjadi
[Boarding](/terminal-operator/set-trip-as-boarding), staf menetapkan Gate (dan
[Berth](/terminal-staff/berths)) untuknya — hanya Gate **aktif** di Port asal
perjalanan yang dapat dipilih.

> **Gates → Create Gate / Actions (Edit · Activate · Delete)**

:::note
Anda membutuhkan permission untuk mengelola Gate. Tangkapan layar di bawah
menggunakan `https://ts-terminal.sindoferry.com.sg/`.
:::

## Daftar Gates {/* #the-gates-list */}

Buka **Gates** (route: `/gates`). Setiap baris menampilkan **Code**, **Name**,
**Port**, dan **Status** (**Active** / **Inactive**) Gate, serta menu **Actions**
(**⋯**). Gunakan kotak **search** (mencocokkan kode dan nama) dan **Show Filters**
(Port, Status) untuk mempersempit daftar.

![Tampilan daftar Gates](/img/terminal-staff/gates/01-gates-list.png)
_Daftar Gates — Code, Name, Port, dan Status. Perhatikan **G1** muncul di dua Port berbeda: kode hanya harus unik **di dalam** satu Port._

## Membuat Gate {/* #create-a-gate */}

Klik **Create Gate** (kanan atas) dan isi formulir **New Gate**:

| Kolom | Catatan |
| --- | --- |
| **Port** | Port tempat Gate berada — pilih ini terlebih dahulu. |
| **Gate code** | Kode Gate, misalnya `G1`. |
| **Name** | Nama deskriptif, misalnya `North Wing Gate 1`. |
| **Active** | Apakah Gate tersedia untuk ditetapkan. Tercentang secara default. |

Lalu klik **Create Gate**.

![Formulir New Gate, berisi Port, Gate code, Name, dan kotak centang Active](/img/terminal-staff/gates/02-create-gate.png)
_Membuat Gate — pilih **Port** terlebih dahulu, lalu kode dan nama._

:::warning[Unik di dalam Port]
**Gate code** harus **unik di dalam Port yang dipilih** (dua Port masing-masing
boleh memiliki Gate `G1`, tetapi satu Port tidak boleh memiliki dua).
:::

## Mengubah, Mengaktifkan/Menonaktifkan, dan Menghapus {/* #edit-activatedeactivate-and-delete */}

Dari menu **⋯ Actions** pada baris, Anda dapat **Edit** Gate, **Activate /
Deactivate** Gate (hanya Gate aktif yang dapat ditetapkan ke perjalanan Boarding),
atau **Delete** Gate (perlu konfirmasi).
