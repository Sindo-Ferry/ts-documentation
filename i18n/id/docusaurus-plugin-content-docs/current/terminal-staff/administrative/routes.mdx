**Route** menghubungkan **Port asal** ke **Port tujuan**. Route dipakai oleh
[Timeslot](/terminal-operator/create-timeslot) dan oleh perjalanan yang dibuat
darinya, dan **trip code**-nya menjadi bagian dari kode setiap perjalanan.

> **Routes → Create Route / Actions (Edit · Activate · Delete)**

:::note
Anda membutuhkan permission untuk mengelola Route. Tangkapan layar di bawah
menggunakan `https://ts-terminal.sindoferry.com.sg/`.
:::

## Daftar Routes {/* #the-routes-list */}

Buka **Routes** (route: `/routes`). Setiap baris menampilkan **Code**, **Name**,
**Trip Code**, **Origin Port**, **Destination Port**, dan **Status** (**Active** /
**Inactive**) Route, serta menu **Actions** (**⋯**). Gunakan kotak **search** dan
**Show Filters** untuk mempersempit daftar.

![Tampilan daftar Routes](/img/terminal-staff/routes/01-routes-list.png)
_Daftar Routes — Code, Name, Trip Code, Origin/Destination Port, dan Status._

## Membuat Route {/* #create-a-route */}

Klik **Create Route** (kanan atas) dan isi formulir **New Route**:

| Kolom | Catatan |
| --- | --- |
| **Route code** | Kode pendek yang unik, misalnya `RTE-001`. |
| **Name** | Nama deskriptif, misalnya `Harbourfront to Waterfront`. |
| **Trip code** | Kode pendek yang dipakai di kode perjalanan yang dibuat, misalnya `HW`. |
| **Origin Port** | Port keberangkatan Route. |
| **Destination Port** | Port kedatangan Route. |
| **Active** | Apakah Route tersedia untuk dipakai. |

Lalu klik **Create Route**.

![Formulir New Route](/img/terminal-staff/routes/02-create-route.png)
_Membuat Route._

:::warning[Aturan validasi]
- **Route code** dan **Trip code** masing-masing harus **unik** di antara semua
  Route.
- **Destination Port** tidak boleh **sama dengan Origin Port**.
:::

## Mengubah, Mengaktifkan/Menonaktifkan, dan Menghapus {/* #edit-activatedeactivate-and-delete */}

Dari menu **⋯ Actions** pada baris, Anda dapat **Edit** Route, **Activate /
Deactivate** Route, atau **Delete** Route (perlu konfirmasi).

:::info[Delete diblokir jika masih dipakai]
Route **tidak dapat dihapus** selama masih dipakai di **Timeslot**, **perjalanan**,
atau dirujuk oleh **Trip Sync Job** — jadikan Route **inactive** sebagai gantinya.
:::
