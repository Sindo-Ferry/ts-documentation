Tanda **Admin** bukan role. Ini adalah pengecualian yang memberi pengguna **akses
penuh ke semua hal**, sepenuhnya mengabaikan role dan permission-nya.

> **Users → ⋯ → Grant Admin / Revoke Admin → konfirmasi**

**Permission yang dibutuhkan:** `terminal.security.is_super_admin`

:::danger[Admin melewati setiap pemeriksaan permission]
Konfirmasinya menyebutkan dengan jelas: memberi admin memberikan pengguna _"full
access to all system features, **bypassing standard role restrictions**."_

Tidak ada pengaturan [role](/terminal-administrator/add-role) atau
[permission langsung](/terminal-administrator/manage-user-permissions) yang membatasi
Admin. Berikan hanya kepada yang benar-benar perlu mengelola portal — bukan sebagai
jalan pintas saat role sulit diatur dengan tepat.
:::

:::note
Anda membutuhkan permission di atas. Tangkapan layar di bawah menggunakan
`https://ts-terminal.sindoferry.com.sg/`.
:::

## Sebelum Memulai {/* #before-you-start */}

- Anda sudah masuk ke Terminal Portal — lihat
  [Masuk ke Terminal Portal](/terminal-staff/sign-in).
- Anda adalah **Super Admin**. Administrator biasa melihat item menunya dalam keadaan
  nonaktif.

## Langkah 1 — Temukan Pengguna {/* #step-1--find-the-user */}

Buka **Security → Users**. Administrator yang sudah ada memiliki badge **Admin** di
kolom **Status**; pemilik sistem memiliki badge kuning **Super Admin**.

## Langkah 2 — Berikan atau Cabut {/* #step-2--grant-or-revoke */}

Dua cara, dialog yang sama.

**Dari daftar** — menu **⋯** pada baris → **Grant Admin** atau **Revoke Admin**.

![Menu baris yang menawarkan Grant Admin](/img/terminal-staff/security/14-grant-admin-from-list.png)
_Pengguna yang bukan Admin — menunya menawarkan **Grant Admin**._

![Menu baris yang menawarkan Revoke Admin](/img/terminal-staff/security/17-revoke-admin-from-list.png)
_Seorang Admin (perhatikan badge **Admin**) — item yang sama bertuliskan **Revoke Admin**._

**Dari profil pengguna** — **⋯ → Manage Security** membuka **User Security
Profile**, yang menampilkan **Admin Access: Enabled / Disabled** dan tombol **Grant
Admin** / **Revoke Admin** yang sesuai. Tombol ini nonaktif di profil Super Admin
sendiri.

![Panel Admin Access dengan Grant Admin](/img/terminal-staff/security/15-grant-admin-from-detail.png)
_**Admin Access: Disabled**, dengan **Grant Admin** di sampingnya._

![Panel Admin Access dengan Revoke Admin](/img/terminal-staff/security/18-revoke-admin-from-detail.png)
_**Admin Access: Enabled** — badge **Admin** di samping nama, dan **Revoke Admin** di sampingnya._

:::warning[Di halaman profil, Admin biasa melihat tombol yang tidak akan berfungsi]
Di Terminal Portal, tombol **Grant Admin** / **Revoke Admin** di halaman profil
ditampilkan kepada setiap **Admin** — tetapi perubahannya hanya diterima dari
**Super Admin**. Admin yang mengkliknya dan mengonfirmasi akan mendapat error, dan
tidak ada yang berubah.

Jika itu terjadi, Anda bukan Super Admin. Menu **⋯** di daftar Users adalah panduan
yang lebih andal: item tersebut dinonaktifkan bagi siapa pun yang sebenarnya tidak
dapat menggunakannya.
:::

## Langkah 3 — Konfirmasi {/* #step-3--confirm */}

**Memberikan:**

> **Grant Administrator Privileges?** — This will grant **[username]** full access to
> all system features, bypassing standard role restrictions.

**Mencabut:**

> **Revoke Administrator Privileges?** — This will remove administrative overrides
> for **[username]**. They will revert to standard role-based access.

![Dialog Grant Administrator Privileges](/img/terminal-staff/security/16-confirm-grant.png)
_Konfirmasi pemberian._

![Dialog Revoke Administrator Privileges](/img/terminal-staff/security/19-confirm-revoke.png)
_Konfirmasi pencabutan._

Klik **Confirm Grant** / **Confirm Revoke** (atau **Cancel** untuk membatalkan).

## Yang Berubah {/* #what-changes */}

| | Memberikan | Mencabut |
| --- | --- | --- |
| Akses | Semuanya, langsung | Kembali ke role dan permission langsungnya |
| Role | Tidak disentuh — tetap ada, hanya tidak berpengaruh selama Admin | Kembali berlaku |
| Badge | **Admin** muncul di barisnya | Hilang |

:::warning[Mencabut bisa membuat seseorang tanpa akses sama sekali]
Pengguna yang dijadikan Admin **sebelum** diberi role tidak memiliki akses dasar sama
sekali. Cabut tandanya dan ia kembali ke nol — bisa masuk tetapi hampir tidak melihat
apa pun.

Sebelum mencabut, buka tab **Roles**-nya dan pastikan ada yang menjadi sandarannya.
Lihat [Memberikan Role kepada Pengguna](/terminal-administrator/assign-role).
:::

## Admin vs. Super Admin {/* #admin-vs-super-admin */}

| | **Admin** | **Super Admin** |
| --- | --- | --- |
| Fungsinya | Akses penuh ke fitur portal | Akses penuh **ditambah** kontrol keamanan — permission role, role pengguna, permission langsung, dan pemberian admin |
| Cara mengaturnya | Diberikan di sini oleh Super Admin | Tidak dapat diatur dari portal |
| Dapat dicabut | Ya | **Tidak** — _"Super Admin's administrator priviledges cannot be revoked."_ |
| Dapat dinonaktifkan | Ya | **Tidak** |
| Dapat dihapus | Ya, setelah tidak aktif | **Tidak** |

Super Admin adalah akun pemilik sistem. Akun ini ada agar portal tidak pernah
terkunci dari administrasinya sendiri, dan karena itu tidak ada tindakan merusak yang
berlaku padanya.

:::info[Mengapa halaman keamanan membutuhkan Super Admin]
[Permission role](/terminal-administrator/manage-role-permissions),
[role pengguna](/terminal-administrator/assign-role), dan
[permission langsung](/terminal-administrator/manage-user-permissions) semuanya
mengunci tombol tindakannya untuk Super Admin — sehingga Admin biasa dapat
menjalankan portal tetapi tidak dapat diam-diam memperluas aksesnya sendiri.
:::
