Jika Anda bekerja untuk lebih dari satu operator feri, **Switch** memindahkan Anda
antar workspace tanpa harus keluar lalu masuk lagi.

> **Switch (kanan atas) → Select Operator → pilih workspace**

:::warning[Semua yang Anda lihat dan lakukan dibatasi ke workspace saat ini]
Perjalanan, penumpang, Vessel, Timeslot, dan laporan semuanya milik operator yang
sedang Anda pilih. Meng-check-in penumpang, atau mengganti Vessel, saat workspace
yang **salah** aktif akan memengaruhi data operator tersebut.

Periksa **nama dan logo operator di kiri atas** sebelum bertindak.
:::

## Langkah 1 — Periksa Operator yang Sedang Aktif {/* #step-1--check-which-operator-you-are-in */}

**Logo dan nama** operator ada di kiri atas setiap halaman, di samping tombol menu.
Itulah satu-satunya acuan workspace mana yang sedang aktif.

![Header Operator Portal dengan nama operator dan tombol Switch](/img/ferry-operator/sign-in/04-my-operator.png)
_Operator aktif — **SINDO FERRY PTE LTD** — di kiri atas header, dan **Switch** di kanan atas._

## Langkah 2 — Klik Switch {/* #step-2--click-switch */}

Di layar desktop, klik **Switch** di kanan atas header.

Di layar sempit atau ponsel tidak ada tombol **Switch** — buka menu **avatar akun**
di kanan atas dan pilih **Switch Operator**.

## Langkah 3 — Pilih Workspace {/* #step-3--pick-the-workspace */}

Anda kembali ke layar **Select Operator** dengan daftar operator yang tersimpan.

- **Operator yang sudah biasa Anda pakai:** klik kartunya, atau cari dengan kotak
  **search**.
- **Operator baru:** ketik **Operator Code**-nya di **Enter operator code…** lalu
  klik **+** untuk memverifikasi dan menambahkannya.

![Layar Select Operator dengan Operator Code sudah diisi](/img/ferry-operator/sign-in/02-select-operator.png)
_Layar Select Operator — pilih workspace yang tersimpan, atau tambahkan dengan kode._

Anda tiba di **Dashboard** operator tersebut, dan nama di kiri atas ikut berubah.

## Apa yang Dilakukan dan Tidak Dilakukan Switch {/* #what-switching-does-and-does-not-do */}

| | |
| --- | --- |
| **Anda tetap masuk** | Switch hanya mengganti workspace. Sesi akun Anda tidak tersentuh, jadi tidak perlu password. |
| **Operator tersimpan tetap ada** | Daftarnya tersimpan di browser ini. Menghapus data situs, atau memakai komputer atau browser lain, berarti harus memasukkan kode lagi. |
| **Pekerjaan yang belum disimpan hilang** | Dialog yang terbuka — misalnya formulir check-in yang baru setengah diisi — dibuang. Selesaikan atau batalkan terlebih dahulu. |
| **Permission berlaku per workspace** | Permission Anda bisa berbeda di setiap operator, sehingga sidebar bisa tampak berbeda setelah berpindah. |

## Menghapus Operator dari Daftar Anda {/* #removing-an-operator-from-your-list */}

Di layar **Select Operator**, setiap kartu tersimpan memiliki ikon **tempat sampah**.
Menghapus workspace hanya mengeluarkannya dari daftar di perangkat ini — tidak
menyentuh akun Anda atau data operator, dan Anda dapat menambahkannya kembali dengan
kode.

Sebaiknya dilakukan saat Anda berhenti bekerja untuk suatu operator, agar tidak
terpilih karena kesalahan.

## Keluar Sepenuhnya {/* #signing-out-completely */}

**Switch Operator** **tidak** mengeluarkan Anda. Untuk mengakhiri sesi:

- Dari layar **Select Operator**, klik **Sign out of account** di bagian bawah;
  atau
- Dari halaman mana pun, buka menu **avatar akun** di kanan atas dan pilih opsi
  keluar.

:::tip[Di komputer konter bersama, keluar — jangan hanya berpindah]
Switch membuat akun Anda tetap masuk, sehingga orang berikutnya dapat membuka setiap
workspace yang Anda simpan. Di akhir shift pada komputer bersama, keluarlah dengan
benar.
:::
