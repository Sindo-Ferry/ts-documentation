**Manifest** adalah daftar penumpang resmi sebuah perjalanan. Ini jalur cepatnya: dua
klik dari perjalanan, sebagai file Excel dalam bahasa Inggris atau Indonesia.

> **Departure Trips → perjalanan → Download Manifest → English / Indonesian**

:::tip[Butuh PDF, status penumpang lain, atau kata sandi?]
Tombol ini selalu menghasilkan **file Excel berisi penumpang Boarded**. Untuk
kebutuhan lain — PDF, semua penumpang, hanya yang dibatalkan, atau perlindungan kata
sandi — gunakan
[Mengekspor Laporan Manifest Penumpang](/ferry-operator/export-manifest-report).
:::

## Sebelum Memulai {/* #before-you-start */}

- Anda sudah masuk dengan operator yang benar terpilih — lihat
  [Masuk](/ferry-operator/sign-in).
- Anda memiliki permission export-manifest; tanpanya tombol tidak muncul.
- Perjalanan berstatus **Closed** atau **Departed**.

## Kapan Tombolnya Berfungsi {/* #when-the-button-works */}

:::info[Closed sudah cukup — tidak perlu menunggu keberangkatan]
Di **portal operator**, manifest terbuka segera setelah perjalanan **Closed**.
Halaman Current Trips milik terminal menunggu **Departed**, jadi Anda mungkin dapat
mengambil daftarnya lebih dulu daripada terminal.
:::

| Status perjalanan | Download Manifest |
| --- | --- |
| Scheduled | **Nonaktif**, tooltip: _"Available once the trip is closed or departed."_ |
| Boarding | **Nonaktif**, tooltip yang sama |
| **Closed** | **Aktif** |
| **Departed** | **Aktif** |
| Cancelled | Nonaktif |

Tombolnya **nonaktif, bukan disembunyikan** — jadi jika Anda sama sekali tidak
melihatnya, itu masalah permission, bukan status.

## Cara 1 — Dari Grid Perjalanan {/* #method-1--from-the-trip-grid */}

Buka **Departure Trips** dan temukan perjalanannya. Selnya memiliki tindakan
**Manifest** di samping **View**. Klik lalu pilih bahasanya.

![Tombol Manifest pada sel perjalanan dengan menu bahasanya](/img/ferry-operator/departure-trips/07-download-manifest-from-grid.png)
_**Manifest** pada sel perjalanan Departed, dengan pilihan **English** dan **Indonesian**._

Paling cocok saat Anda mengambil manifest beberapa perjalanan berturut-turut.

## Cara 2 — Dari Halaman Detail Perjalanan {/* #method-2--from-the-trips-detail-page */}

Klik **View** pada perjalanan, lalu **Download Manifest** di kanan atas halaman
detail, dan pilih:

- **English**
- **Indonesian**

![Tombol Download Manifest di halaman detail perjalanan dengan menu bahasanya](/img/ferry-operator/departure-trips/08-download-manifest-from-detail.png)
_**Download Manifest** di kanan atas halaman detail perjalanan Departed._

Tombol bertuliskan **Downloading…** selama file dibuat.

Paling cocok saat Anda ingin memeriksa detail dan hitungan perjalanan sebelum
mengambil daftarnya.

## Yang Anda Dapat {/* #what-you-get */}

File Excel (`.xlsx`) bernama:

```
passenger-manifest-<TRIP-CODE>-<TRIP-DATE>.xlsx
```

misalnya `passenger-manifest-SSFHW202607031300-2026-07-03.xlsx`.

Isinya **hanya penumpang Boarded**, diurutkan berdasarkan jam check-in, dengan detail
perjalanan serta **No**, **nama**, **jenis kelamin**, **tanggal lahir**,
**kewarganegaraan**, **negara penerbit**, **tanggal terbit / kedaluwarsa**, **nomor
boarding pass**, **jenis penumpang**, dan **status** setiap penumpang.

:::info[Kedua bahasa mencantumkan orang yang sama]
Indonesian mengubah **teks judul dan label**, bukan penumpangnya. Unduh keduanya dan
barisnya sama persis.
:::

## Memastikan File-nya Benar {/* #checking-the-file-is-right */}

Manifest hanya mencantumkan penumpang **Boarded**. Penumpang yang sudah check-in
tetapi tidak pernah naik, dan penumpang yang dibatalkan, tidak dicantumkan — jadi:

> **jumlah baris di file = hitungan Boarded perjalanan**

Bandingkan dengan angka **Boarded** di halaman detail perjalanan, bukan
**Checked-In**. File yang terlihat pendek biasanya memang benar.

## Pemecahan Masalah {/* #troubleshooting */}

| Masalah | Penyebab | Solusi |
| --- | --- | --- |
| Tombol berwarna abu-abu | Perjalanan masih Scheduled atau Boarding | Arahkan kursor untuk melihat tooltip; tunggu terminal menutup perjalanan |
| Tidak ada tombol di mana pun | Anda tidak memiliki permission export-manifest | Tanyakan ke administrator Anda |
| Baris lebih sedikit dari perkiraan | Hanya mencantumkan penumpang **Boarded** | Bandingkan dengan hitungan Boarded |
| _"The manifest was generated but could not be saved. Please try again."_ | Browser tidak dapat menyimpan file | Periksa folder unduhan dan pengaturan browser, lalu coba lagi |
| Anda butuh PDF atau status lain | Tombol ini hanya Excel + Boarded | Gunakan [laporan Passenger Manifest](/ferry-operator/export-manifest-report) |
